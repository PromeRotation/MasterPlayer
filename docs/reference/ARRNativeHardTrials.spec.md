## Geocrush 的有据修正

当前 BMR `T07TitanH.cs:63–68` 在存在外圈时提前return，使内圈始终不可达。已核对相邻完整仓库历史提交 `b40a8bf8e1355d4837e7a11579a9961379ce1ac1`（2025-03-12，`lets have more ref structs and less ienumerables`）：它把父提交 `5fc6657a0f0a901d799464cfb697c69c9218aeed` 的两次连续yield错误改成两次提前return。

MP恢复历史可观察行为：前3次开始分别登记23–25、20–25、15–25持续外圈，同时登记R21/R18/R13定时内圈；结束只清内圈。正式R25场地不缩小，计数按start推进，取消不回滚。第四次及以后保持源码回落R25，即定时内圈R23；25–25零面积环不注册，避免外扩产生虚假危险。不得无依据将后续半径钳制到15或清除外圈。

内外圈使用精确几何模板，避免门面和解算器双重余量消灭两码环带。默认解算参数的真实路径回归要求到达内外圈之间。内圈源码仍带falloff待核注释；历史证据不替代实录校准。
