# 永护塔底原生迁移

区域 `1266`，CFC `1027`，入口 `masterplayer.dungeon.underkeep`。三个 Boss 由 MP 脚本、原生状态与本地几何驱动，生产实现不创建 BMR 模块或会话。

- Gargant：72 边场地从源解析后的多边形导出。沙球创建后 7.9 秒激活，按创建回调顺序保存；公开首项时间加 1 秒以内的严格连续前缀，不排序、不跨越较晚项。读条结束只消费队首，Effect、销毁无读条的球及预测过期均不消费。创建事件晚于对象快照时修正时钟与回调顺序，已消费项不恢复。Trap Jaws 保留读条时目标（自目标时回退当时攻击目标），直到同技能的真实主目标命中才消费。
- Soldier S0：模型三元组变化恢复左右方向；313 连线计数，327 连线建图。43163/43164 激活首分身后，仅在剩余边少于分身数时，由首分身的出边目标位置与朝向生成半场。六分身预测为更新时刻加 4.2 秒，其余加 5.9 秒。42566/42567 结束清队列，但保留源的 active/direction 语义。同 ID 连线换目标先断旧边，事件先于快照时等待原始状态确认。
- Valia Pira：时间线创建十字与两个起点，中点决定源的两/三项比较顺序；只公开首十字。初始各轮首项为 8.3/11.4/7.3 秒，首轮第二项为 11.4 秒。282 传送修改首个匹配球位置，然后按轮次重排为 `[.6,7.9,14.4]` 或 `[2.8,7.9]` 秒。事件晚于快照时只修正此次尚存预测的时钟，不重复移动或恢复已消费项。42737 按施法位置删除首个逐轴 1 码内的匹配项，整批清空才推进轮数。
- 两种诱导扇形按 icon 时刻加 5.1/7.4 秒生成，动态绑定首领及目标，真实 Effect FIFO 清理，目标死亡清理；点名者显示轮廓并按队友方向回避 R100 扇形，其他人避实际扇形。525 直线分摊使用事件施加者为源，目标必须存在，5.3 秒预测，42540 任意 Effect 消费队首；保留死亡目标和源死亡隐藏语义。点名者靠近未点名队友、避其他加倍宽分摊，未点名者进入恰好一个分摊。
- 普通 AOE 保留锁定读条位置/朝向和包修正，分散跟随目标最终状态，按技能结束清理。对象销毁先派发其读条结束语义。临时脱战保留，Boss 死亡结束；Reset、Seek、Stop 清理各自 owner 输出。雷达/世界预览共用原尺寸，本地导航单独应用危险余量。

源没有本区专用视线、护盾禁攻、强制面向、停手或禁止移动判定，不新增推测机制；继续使用 MP 移动总开关、回放禁执行及 PR 控制门面。

验证：`tests/UnderkeepRegression.cs` 33 项通过，含源场地/几何与世界转换逐点对照、创建及连线先后顺序、时钟、FIFO、包修正、动态目标、死亡/销毁和实际时序解算路线。`NativeDungeonReplayUnderkeep.cs` 以实际 DLL 验证三个 Boss 的事件路由、预览与危险区、连续机制及 Seek。主项目构建成功，93 个内置入口独立编译及全地城合成回放通过。

离线结果不代表 ARR 实录校准、游戏内像素显示或 PR 实际输入验收；上述实机项目仍待验证。
