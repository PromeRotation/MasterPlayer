## 场地与几何绑定

- 各课程使用各自的真实可走轮廓与逐段路线，保留桥面、坡道、转弯和空洞，不使用统一圆形边界。绘制按玩家附近 100m 筛选；未知玩家位置不画。导航只取当前目标附近的局部边界和危险区。
- 自身读条形状使用包捕获的 `SourcePosition` 与锁定 `CastRotation`，扫描缺失读条时使用对象源位置和原生 `CastRotation`。保留包内 `EffectPosition` / 原生 `CastInfo.TargetLocation` 供35409的两点冲锋。无源位置时跳过，不用落点顶替自身源点；无朝向的圆形仍可显示，矩形/扇形跳过并记录一次诊断。
- 同轮扫描只补缺，不能覆盖已锁定的位置/朝向；读条包可以校正扫描先建立的快照。34797/98普通源/效果朝向为0/π，而包内读条朝向为±π/2，效果后的短暂显示沿用读条几何；未捕获读条时不根据错误效果朝向画扇形。
- helper 的无读条 ActionEffect 使用事件发生时的源位置/朝向，保持静态快照 0.55s，不跟随其后瞬移。效果窗口是显示驻留时间，不声称真实危险持续0.55s。
- 滚动球（16351）随对象移动；销毁、死亡即清除。连续球效果包不额外叠加旧位置圆圈。
- 新第二关旋转长条34808实时跟随已激活的9020 helper；0.62s效果间隔，显示超时1.3s，首次效果前不声明已激活。100×8参数来自客户端，录像效果无命中目标，碰撞与世界视觉关系待实机确认。
- 冲锋路线宽3，两个以上实际位置才形成描边；最后观测超过8s、源消失或死亡清除。路线描边表示已观测的活动范围，不声称整条路线同时危险。

## 自动竞速与比赛门控

- 脚本设置为“自动竞速（走位、跳跃与搬运）”，默认开启；“竞速路线与机制处理”机制组可以独立关闭。开启后取得可撤销的本地移动请求，不修改用户全局智能躲避或 PR 配置。
- 比赛以 DirectorUpdate 的实例 **0x8004002B** 为准。命令 **5** 为准备；**0x80000001 + stage 0x4E2D–0x4E31** 为课程开始；**7** 为本地资格；**6/8** 为结束。命令2倒计时和0x80000001的参数0/1不释放竞速输入。相同开始信号重复到达不能重置当前进度。
- 中途启用时，只在当前课程已有进展及特有状态/活动读条证据、没有准备/观战/起跑锁定时保守恢复。资格或结束后禁止因留在赛道上的坐标重新启动，等待下一轮准备或真实开始信号。
- 路线逐段前进，转弯受场地轮廓约束；Ring 循环沿外围生存，直到资格/结束事件停止。颜色搬运和 FirstB 恢复使用各自路线，不直接连线穿越空洞。
- 导航危险来自锁定读条、校时波浪及实时机关。滚动球跟随实际位置；往返机关的历史路线描边不作为整条同时危险。首个无读条效果之前没有可靠周期时，不编造开启时间。

## 宿主输入与生命周期

- PR特殊方向输入复用宿主 **GreenMove hook**；MP不安装第二套行走hook。MP负责课程状态、SafeZone解算目标、跳跃及限时朝向请求。实时操作仅在区域1165、有效本地玩家、非回放且比赛进行中授权。
- **PR自身自动移动开启或宿主正在控制移动时，MP让位**。实机测试需关闭PR自身自动躲避/自动移动，开启MP脚本的“自动竞速”，避免因宿主所有权使竞速输入暂停；不会替用户改动PR配置。
- 起跑前启用脚本并装好配套DLL。已经开跑后仍站在初始点才热载，可能错过Director开始事件；没有可靠比赛进行信号时保守等待，不能解除准备期门控。
- ActionEffect 按 `(SourceId, ActionId, GlobalSequence)` 去重，保留有限512项。序号0按来源/动作/位置的预览ID覆盖，不堆叠目标展开事件。
- 打断/取消撤销尚未命中的读条及其波浪链；正常读条结束等待效果或超时。对象扫描识别提前停止的读条，不使取消的链复活。
- 源死亡/移除撤全部关联绘制；区域离开、脚本停止、回放倒退全部清理。比赛结束不依赖 `OnBattleEnded`，小游戏不一定设置战斗旗标。
- 双视图使用 `AddAoePreview`，按机制分组，服从用户世界/雷达开关与颜色。绘制预览与导航注册分开：预览接口本身不移动玩家；竞速机制通过独立导航适配器注册目标、边界和危险时间窗。
- 回放读取 `ReplayWorld`，不回退实时对象表。全部时间使用宿主 `CurrentTime` 与录制事件时间。
