# 创生设施 MP 原生脚本

本机简中客户端表双向确认 CFC 825 ↔ Territory 1208，正式副本名为「魂魄工厂创生设施」。入口 `Presets/Dungeons/Entries/Origenics.cs`，实现位于 `Presets/Dungeons/Origenics/`。生产脚本只使用 MP 状态、几何和门面，不创建运行库模块或会话；BMR 源码仅作对照及离线几何导出。

## 范围与生命周期

迁移 `D050OrigenicsAerostat`、`D051Herpekaris`、`D052Deceiver`、`D053Ambrose` 四模块。道中集合 41E2/42BA/43D6/4189/43D7 全死或销毁才结束；激活后成员移动、脱战、不可选不终止场次。Boss 启动后同样保留临时脱战或不可选状态，主怪死亡或销毁才结束。

道中复杂六边形节点及连接区、Deceiver 八种挖除场地从源解析后的多边形离线导出为 MP 几何；双视图使用同一原生形状。普通读条危险区由实际 Finish/取消/来源销毁结束，不以到期定时删除事件序列。

## Herpekaris

- WrithingRiot 36465/36466 为 R25、总角210°；36467 为总角90°。提示开始时按当前事件时钟 `Now+7.3−追加前队列长度` 建立，不排序。仅显示前二；队首始终危险，有后续时黄色持久；第二项与队首形状相同时变为非危险，后续不主动恢复。实际 36469/36470/36471 每击 FIFO 消费一项，提示 Finish 不消费。另在队首激活时发布来源三码内站位约束。
- 毒池 36460 分为动态读条预测、事件锁定位置后延迟0.9秒的预测、1E9E3C 对象三阶段。读条优先跟随施法者当前目标，缺目标取当前 CastInfo 落点；事件优先取目标位置，缺目标取事件落点。每次对象更新、每个 EventState != 7 的毒池最多移除一条两码内事件预测，预测无自然超时。对象不按 Dead/Targetable 排除，绘制位置量化。
- 36474 marker 来源建立长50、全宽8直线分摊，预计5.6秒。重复marker不合并；36473实际命中按目标清一条，唯一剩余时可按可解析实际目标纠正。来源死亡隐藏，目标死亡保留；预测共享伤害、点名聚拢及非点名入线约束跟随当前视角。
- 36518 延迟死刑保留多目标列表，Finish 不清，实际命中按目标移除；37921 分散、38518/38519 R6组保留。

- 命中安全墙按角色hitbox扣除边缘余量；有墙但未命中时裁到当前场地边界外 `0.5−0.499`；无墙则完整位移30。免疫只跳过位移预览，自定义站位约束保留。任意36367 Finish清全部来源和提示。

## Ambrose
