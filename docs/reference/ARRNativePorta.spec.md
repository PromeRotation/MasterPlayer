- 29003 径向击退15、撞墙停止；导航要求进入中心R5，即使有击退免疫仍保留该站位。免疫按判定时刻有效性只撤销位移落点预览。

- 第一阶段死亡或切换至第二阶段时清旧场地、护盾、区域和个人输出。源未激活的转场长读条与监狱技能仅参与通用躲避接管，不按枚举注释扩成额外危险区。

- 29012 分散显示R6、导航间距R7；29014四人分摊显示R6，点名者靠非点名队友R3，其他人按圈内人数3/4/5与是否身在圈内选择进入或避开。两个独立组件分别维护点名集合，不能交叉排除对方目标。目标移动实时跟随、死亡隐藏，结束按Action+Target删首项；不新增源未提供的分摊/分散伤害预测。
