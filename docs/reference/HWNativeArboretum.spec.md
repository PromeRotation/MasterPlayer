## 旧式地图事件输入

匹配的 FFCS 7.57.0.9681 提供 `EventFramework.SetDirectorData`。MP 原生 hook 先执行原函数，再复制 UnionData 入队，由 Framework 主线程派发到脚本与录制器；不向 PR 总线发布合成事件。有效长度上限 4096，空数据合法，完成判定对空数组/null 防护。安装或捕获失败有明确错误日志。

`LegacyMapEffectEvent` 是本地 LogSystemEvent 派生类型，脚本总事件订阅与显式类型订阅均可接收，停止脚本按 owner 清理。进入和退出 MP 回放都清除待发实时输入，回放期间不采集到 live 队列；切区清除旧输入。卸载与原函数调用串行，已进入 detour 的调用使用 Dalamud `OriginalDisposeSafe`。

录像 v2 继续使用既有 JSONL 结构，写 `kind=LegacyMapEffect` 和本地具体类型；读取侧只对白名单内的本地类型放行。旧读取器按未知事件跳过；缺少此事件的旧录像不能重建首段完成状态。
