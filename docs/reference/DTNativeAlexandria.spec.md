## 生命周期与验证边界

三个Boss均在可选且战斗中启动，激活后临时不可选/脱战不重置，主怪死亡或销毁结束。通用危险区接管按区域与Boss OID隔离，输出使用本地Registry、统一雷达/世界预览和MP移动门控。源三模块没有独立护盾禁攻、视线、强制面向或停手机制，因此沿用既有MP/PR门面，不根据技能名虚构额外控制。

`tests/AlexandriaRegression.cs`覆盖源形状/雷达/世界逐点对照、混合队列及包修正、第五次计数顺序、三段真实事件时钟、图标顺序与slot、软目标/两秒严格边界、人数排除、同目标FIFO、独立线组件、击退SDF、免疫、死亡/复活/销毁缓存和选择性地图取消。实际DLL合成回放位于 `tests/ScriptCompilation/NativeDungeonReplayAlexandria.cs`，覆盖三个Boss事件路由、Seek、停止与绘制/导航接线。

合成世界帧和几何转换验证不等同于ARR实录或游戏内像素/PR实际移动验收；这些仍需实机确认。

验证结果：44项定向回归通过；CI编译0错误；实际DLL发现、89个内置入口独立编译和全部原生地城合成回放通过。迁移审计更新至251个原生离线验证类型、936个待迁类型；地城尚余29个BossModule。
