八种静态场地从对应来源解析后的多边形导出。馆长动态格子用 MP 外环、孔洞和填充三角形实现，对角接触拆成简单环，显示轮廓不包含内部格线。雷达、世界转换与导航消费同一真实场地；危险区预览保持原尺寸，导航余量只应用一次。
