三场持续顺劈按 Boss 到当前目标方向绘制轮廓；非受击者避扇形，受击者按存活队友方向生成 R100 禁区。危险内文字提示同步消费持续顺劈与风眼。倒数仍保留一位小数，逐次更新界面状态，日志按机制键节流。

迦楼罗未读条时，石柱周围 R5 仅参与导航；任意 Boss 读条期间解除。视线在读条开始冻结真实柱体位置与 hitbox，包含仍存在的死亡/不可选中柱；安全阴影从距离+0.2开始，半角 asin(hitbox/距离)，延伸到31.7，并扣除 hitbox+0.5 柱体圈。安全阴影两视图绘绿，补集用于导航；FIFO 队列只显示第一项。完成、取消、替换及销毁清理对应记录；无柱时不凭空生成遮挡。

普通 AOE 锁定位置/方向，时刻使用已含 NPC 0.3 秒补偿的 FinishAt；持续到观察到实际读条结束。显示原尺寸，导航只应用一次用户余量。源组件未提供的缩场、额外击退或强制玩家面向不根据技能枚举注释增加。石柱遮挡视线与 PR 背对视线是不同机制。
