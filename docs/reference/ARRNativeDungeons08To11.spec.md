## 绘制、规划与生成

读条快照使用包落点和锁定 CastRotation，判定保留 NPC +0.3 秒；无读条沙柱、雷球、漩涡及时间线预测按各自原始事件延迟，不额外添加该补正。导航余量与原尺寸预览分离；原生预览经 AoeVisibilityRegistry 同时供雷达和游戏世界绘制消费。Qarn 安全目标与雷球额外风筝范围使用独立规划通道。

- Qarn 两个小型多边形直接记录原顶点；LocalPolygon 的局部基底通过场地中心减世界坐标转换。
- `tools/export_arr_polygon_arenas.py` 从 Cutters 原始顶点导出三个 MP 多边形。
- 实际 DLL 冒烟工具 `--stonevigil-arenas` / `--dzemael-arenas` 从匹配运行库的已求并差场地导出静态 MP 顶点；逐个拒绝有未处理洞或多部分的拓扑。生产代码不调用该运行库。

## 验证与限制

四本新增共 57 项定向回归：Qarn 14、Cutters 19、Stone Vigil 14、Dzemael 10。覆盖原场地与宿主世界几何逐格比较、读条原尺寸和时钟、连续段、重复效果、取消、消失、死亡、切人、状态移除及真实解算器到达/逃离。

`NativeDungeonReplayRegression` 使用实际 MasterPlayer.dll 的 ScriptManager、ReplayController、安全区和绘制注册表重演四本关键连续机制，覆盖默认发现、Seek 重建、状态采样、场地及输出清理。所有 GreenMove 和实时对象读取在离线测试中均禁止。

尚无这些新版本的实机录像校准；0.9/0.6/3.1/7.8/10.5 秒为匹配上游实现的预测值，不是本轮实测。两视图最终像素效果、实时 FFCS 采样及 PR ACR/面向/原生自动攻击执行仍需游戏内验收。没有部署或卸除全局 BMR 桥。
