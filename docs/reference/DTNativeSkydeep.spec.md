# 深空天坑 MP 原生机制

2026-11-22。本机客户端双向确认 CFC829 → Territory1194，正式名「神圣禁地深空天坑」。入口 `masterplayer.dungeon.skydeep` 接管 OID41D3、4184、41C7 三个模块。生产实现位于 `Presets/Dungeons/Skydeep/`，不创建 BMR 会话或读取桥输出。

来源为 `MechanicRuntime/Upstream/Modules/Dawntrail/Dungeon/D03SkydeepCenote/` 三个模块，以及 BaitAway、StackSpread、Towers、Knockback 公共组件。

## 时序、绘制与控制

- 一王初始半宽15.5方形；36733发布中心12–24月环，实际 Map13/state00020001才清预告并改成48边R12多边形，00080004还原方形。多边形由运行库解析结果离线导出，生产仅保存 MP 顶点。
- 小泡泡精确以 HitboxRadius==1.1 筛选，不限制OID；timeline1E46追加引用，1E3C只删除当前实例第一份登记，允许重复。死亡不删除，销毁或扫描中消失后冻结最后位置/朝向，同ID重建不重绑旧登记。显示R1.1、前3胶囊，导航预测Now+1.5及当前R1.1障碍；36732/38787施法期间额外要求离开中心R5。
- 36736/36737对41D4非1.1半径泡泡分别预测X+8/-8、R6、CastFinish+3.4；36738实际Finish清全组，不重复发布自身读条圈。38185仅移动泡泡，36727没有激活的源组件，不凭注释制造AOE。
- 36728发布Boss前24、总30°扇形，同时建立全部存活本队玩家（不含Buddy）的自身喷吐引导，事件Now+6.3；每帧按本人位置/实际朝向绘制。自身轮廓不参与位置导航，其他玩家扇形填充并参与导航。判定前0.75秒经公共PR面向门面避开所有活本队玩家方向±15°；36729真实effect清玩家喷吐，Boss读条结束不提前清。
- 二王36448为全屏及半宽25减20缩场预告，CastFinish+0.6；Map14/state00020001才换半宽20并清预告。36445R35，38581–84分别前42/49/35/36宽8，38660–63前10宽10独立保留到真实读条结束。36450R6分散、导航R7；36447单体伤害。
- 三王四种Stonecarver前40宽20，恰2条时按激活时间排序；首条被读取时置Risky，双条时黄色持续，不复位此前已置Risky的旧首项。全部条目显示，任意相关Finish统一FIFO消费。存在石刻时要求中心X±1.5、Z±40中线，站位时间优先Impact2首条，否则首石刻。
- Maulwork的Finish建立延迟碎裂。源NPC elapsed封顶，当前适配公式为 `max(cast.FinishAt−0.3, observedFinishTime)+15.4`，覆盖提前结束、正常结束、延迟回调及销毁。中心用锁定施法位置/朝向；两侧固定(91.539,-453.025)/−17.004°、(108.415,-453.025)/16.999°，前45宽22。首条Activation−6到达后整组公开，包括更晚的第二批；36684/85/86任一真实Finish清全，不重复直接绘制Shatter读条。
- Impact1/2/3径向18/18/20，预览为StopAfterWall语义；不同动作组件各自从玩家当前位置开始，同动作按插入顺序连续计算。导航分别要求落点在半宽19方形内，BuildingHeat36710开始→Impact3半宽14、结束→19。免疫只移除实际落点预览，不取消源自定义站位。Impact2额外提示首石刻内或场外的危险落点。
- DestructiveHeat36709始终显示R6分散，只有分散存在时才记忆Impact1固定(100,-400)、否则Impact2/3首来源。没有来源时不发布分散位置导航；有来源则发布R7分散导航及来源R15内站位，击退结束后保留历史来源。
- BuildingHeat36710为独立R6四人分摊，不排除另一个组件的分散点名；自身聚拢队友R3，其他人精确加入一个分摊，避免重叠。36688/36689为两个独立R6四人塔组件，人数决定进入或避满员塔，伤害预测仅塔内成员；36690repeat不清塔。
