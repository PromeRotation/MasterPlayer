# 恩欧歼殛战：视频打法专属预设

## 使用

- 区域 1362，副本 CFC 1116，恩欧 OID `0x4DC1`。
- 在 MP（界面名 PromeRadar）的机制脚本页启用「恩欧歼殛战 · 视频打法」。PR 的队伍排序必须完整指定 MT、ST、H1、H2、D1、D2、D3、D4，不能重复。
- `EnableSmartMovement` 是移动与机制控制总开关。脚本设置「自动插言、驱散、减伤、防击退与冲刺」可单独关闭技能执行。常规输出与治疗继续由 PR 的 ACR 负责。
- 使用本机实际的 PR 1.5.11.1 与 Dalamud CN 开发依赖构建。宿主 `MechanicControl` 已通过接口检测；旧宿主没有此接口时会明确提示，不能声称自动转火或背对已执行。
- 本轮构建使用 `-p:CI=true`，产物在 `bin/Release/`，没有覆盖已安装插件或改变游戏设置。装载时应保留旧插件备份，并由 PR 插件管理器重载。

## 策略与实现

打法来源为[四钱苏木视频 BV1uKRuBkEg7](https://www.bilibili.com/video/BV1uKRuBkEg7)。视频开头称为 BOSS 基准、P2 NOCCHH；其中挡枪的左右以玩家在安全侧面向 BOSS 为准，普通分摊、八方及四塔则采用固定场地标点，不能把整套机制理解成随 BOSS 朝向旋转。Game8 仅用于机制交叉核对，未把它的另一套站位当作视频站位。
