# 克吕提俄斯魔导工厂 MP 原生实现

区域 `1345`，CFC `1011`，入口 `masterplayer.dungeon.clyteum`。源依据为 `MechanicRuntime/Upstream/Modules/Dawntrail/Dungeon/D13TheClyteum/`，三场生产实现不创建 BMR 模块或会话。

- Eye of the Scorpion：中心(-615,575)、半边长20方场。50177/78为R70总100度扇形，按插入顺序只公开前两项；技能名含Petrifying，但源是普通AOE，不另加Gaze。48898落点R5、48899分散实际R5/AI6、48901分摊R6。
- 5191 MotionTracker Gain以ExpireAt设置Stay，Lose清理；快照首次恢复及同状态ExpireAt变化均补发状态，显式事件在匹配快照确认前优先。停手在激活时间严格小于当前+1秒时执行，保留到实际状态解除。
- MotionScanner 4C2D：renderflags0替换单引用光束，16384清引用，其他值不改变。显示矩形前后9、半宽20，控制范围前后10、半宽20。观看角色在控制矩形内时覆盖Stay为当前时刻，在外清Stay；此源Draw副作用移到模拟Tick，关闭绘制仍执行控制。绘制仅显示，不把光束当躲避危险区。其他扫描体16384也可清现有光束，行为与源一致。
- Chort：中心(660,-141)、R15解析圆。48871前40半宽4，50400/48876前40半宽8，50361 R50总120度扇形。48878径向击退8码，导航只要求首条原点R7内；绘制逐条考虑免疫。48882四人塔仅公开激活最早者，同时间保留列表首项，Finish按caster消费，下一塔随之公开；伤害预测仅包含当前塔内队员。
- Icon558为源Actor上的R4、+5秒分散，48885效果按实际目标清首条，找不到时删队首，死亡移除；不从48885读条创建。48887为R6四人分摊。48884/50408源没有激活全屏伤害组件，不虚构预测。
- Malphas：中心(760,-803)、R20解析圆。50313 R30总180度扇形，48933前80半宽2，48937/43 R60总30度扇形，48935/40 R7圆。6.5秒及14.5秒预测均从Start公开并参与规划，保留到实际Finish，不把源TODO误当已有延迟风险阈值。
- 50314分散R6/AI7，48928分散R5/AI6，两者独立计算自己的队友排除集合；48930为R6分摊。普通读条分散死亡过滤、复活恢复，按目标Finish只消费首条。普通读条分散和无禁入成员的分摊遵守源默认伤害预测门控；Icon分散保留其默认预测。
- 48931 StringUp仅接受OID4C28；首次Start回调对当时存活队伍槽设置Move，激活为回调模拟时钟+5秒，恢复在途读条不回溯到原始起点。队伍槽替换继承槽要求，死亡清该槽，Finish/取消清当时存活队伍槽。进入激活前1秒时禁新读条、取消正在读条，并用持续更新的当前位置禁区驱动MP继续移动，结束后释放。

控制链路：扫描Stay进入 `RequireAllStop`，经 `DungeonScript.Render` 调用 `ScriptHintsApi`，联动PR ACR HoldActions/BlockCasts/CancelCast、原生自动攻击停止及MP owner移动暂停；StringUp只禁读条并驱动移动。唯一智能移动总开关、ARR/MP回放隔离和owner生命周期仍由现有门面管理。

验证：`tests/ClyteumRegression.cs`及`ClyteumControlRegression.cs`共31项通过，覆盖源几何逐点、双输出、连续预告、状态刷新、光束范围和覆盖、下一塔、分散重叠、队伍槽与恢复时钟、真实解算路线；控制测试检查PR请求参数、自动攻击停止回调、MP移动保持及回放/总开关释放。`NativeDungeonReplayClyteum.cs`通过实际DLL三场合成回放、Seek及宿主控制隔离；主项目构建及96个内置入口独立编译通过。

仍需ARR实录、游戏内像素绘制及PR实际输入验收；上述控制测试不模拟游戏输入。
