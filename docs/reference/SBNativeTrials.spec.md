## 输入、绘制与验证

元气储存次数不是1290状态。`ReplayWorldCapture` 通过匹配引用的 FFCS `DutyActionManager` 采集动作ID及当前/最大储存次数，最多遍历长度为2的充能数组。新增帧字段 `DutyActionPlayerId` 和可空 `DutyActions`；null表示未知，空数组表示已知无任务技。只允许真实本机玩家使用客户端输入，ARR观看角色不借用本机充能。旧录像未知时仍显示球和提示，不猜零充能、不自动规划取球。暂停、增量、反向Seek从录像恢复，不读取实时对象补齐。

雷达和游戏世界共用原生几何。敌人用现有 MP 圆形轮廓表达；击退用线段及落点圈表达，场外落点标记投影到边界并允许越过场地裁剪，实际落点仍用于危险提示。两者不是上游的人物字形，不能以静态几何验证代替游戏中视觉验收。
