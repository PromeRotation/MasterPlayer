# 中央终端 MP 原生实现

区域 `1292`，CFC `1028`，入口 `masterplayer.dungeon.meso`。三个模块均使用 MP 事件路由、状态、区域与绘制门面；生产代码不创建 BMR 模块或会话。源依据为 `MechanicRuntime/Upstream/Modules/Dawntrail/Dungeon/D11MesoTerminal/`。

- Chirurgeon General：初始半边长21.5方场；43798只预测 `Finish+.8` 的方环，map04/20001才正式缩场。地图大小球先显示不导航，43806只激活前四项并在Finish清全部，43805不消费。43807向外24码的导航只检查半边长19方场；落点显示另外检查全部球和真实场地。中毒2104已接驱散执行器。
- Four Headsmen：保留原Pale引用及三个首次缓存的Boss，已缓存成员全死或销毁才结束。249/341按玩家ID保存分配，仅断341或Gain4550解除；4542–45提供状态兜底，Lose不解除。分配期间所有非指定敌对可选目标进入PR ACR禁攻，严格18码内Hellmaker例外并提供目标优先级，近战有R3目标区域。源没有独立护盾量判定，不把2552/3A3当护盾。
- 监狱：2552/394的当前坐标按0.5取整；用40边的8–8.25环带从源默认场地做差集，保留环内可行走岛。Lose按当时位置删首。未分配视角恢复默认场地，已分配视角使用全部监狱差集；规划、雷达裁剪和世界轮廓共用同一结果。两个地图Hellmaker方区仅未分配者可见并参与导航。
- 连续机制：普通AOE按首项+2秒严格连续前缀，不排序；三连死刑在第三个唯一效果事件后清。剑按创建+5.5开始、51击、最多显示12步；第一步0.24118、第二击起按当时朝向0.3222，后续时间为效果事件+.2。命中终止使用PR `TargetIndex>=0`而非主目标ID；已发布未来步骤不逐帧漂移。死亡清线按源方向/位置条件，销毁按最后位置匹配首线；无读条对象先从快照消失也会执行状态、连线及剑清理。
- Immortal Remains：Icon525直线分摊长60、半宽3、点名+5.2，效果FIFO消费。11D3的terror列表保留重复及最后引用；列表严格大于6才接受18705–08台词。大圈偏移朝向按最近1度取整后前移3.5码，所有圈共用首条台词+9.8，只有43811 Finish清全部。Impression实际监听43818；恰8圈关闭普通导航风险但保留绘制，全部击退结束后恢复。免疫仍禁中心R10，非免疫投影11码并避R4/R15与半边长19方场。Turmoil为效果+4.4，Keraunography为visual Finish+3，保留到45176 Finish。

面向、视线和额外停手机制在本区域源模块中不存在；不添加无来源的控制。禁攻、选敌、驱散、打断均经既有MP/PR执行门控，ARR和MP离线回放只规划绘制。
