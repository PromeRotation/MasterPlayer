## 误导执行与边界

当前PR源码 `GreenMovementInputController` 的误导分支和 `MCIsInputActive` 均限定糖豆人，
`SupportsMisdirection`不表示支持普通区域。MP的 `VanaspatiMisdirectionControl` 因而使用同一
已知输入入口及箭头签名，在万相森国、误导状态、MP移动owner持权且移动总开关允许时介入。
目标取PR实际队列的 `CurrentPoint`，箭头在目标世界方向±15°才开启输入，100ms结果租期，
250ms脚本授权租期；手动输入让位、切区/死亡/切人/停用/总开关/回放撤销。
普通朝向没有另写原生旋转，仍由PR面向接口处理。

该执行代码已编译，输入策略的角度、跨π、容差和无效值有离线验证；MP回放验证不初始化任何native hook。
尚无本场ARR录像/动态字段及实机输入验证，四个通用误导SID是否在当前客户端共享同一箭头字段、
双hook与PR的游戏内链、箭头等待对路线截止时间的影响均待实机确认。不能把离线策略通过称为误导实机成功。
