# 迦巴勒幻想图书馆原生机制

区域 1109，CFC 31。入口 `Presets/Dungeons/Entries/GreatGubalLibrary.cs`，按 E82/E83/E84 固定隔离 BMR；运行仅消费 MP 世界和原始事件时间，不构造运行库模块。

- Demon Tome：默认两片场地与 Disclosure 带孔场地均由真实多边形导出；Disclosure 开始切场，旋转在原读条判定后 2.4 秒，完成读条保留，3989 效果恢复默认场地。Repel 沿读条朝向击退 20 码、忽略免疫并在第一处边界停止；薄冰滑行 15 码，标准移动取角色朝向，传统移动取录制相机方位加 π。未产生上游没有的额外薄冰禁止区。
- Byblos：无敌 325 对相应敌人发布 PR ACR 禁攻，首领顺劈同时撤销；书页优先选敌。HeadDown 为目标动态冲锋矩形，真宽 8；个人导航避免冲到队友。Tomewind 真半径 3，作为障碍；油球连线显示并为点名玩家注册首领 hitbox 目标，取消后旧对象快照不能复活连线。
- Bibliotaph：23 点名原时钟加 5.1 秒，半径 8，首个点名额外去场边。球体锁出生量化位置，出生加 9.8 秒；3780 结束按 FIFO 清除。塔出生加 17.8 秒、半径 3；原始塔数为 2/3/其他时每塔需要 3/2/1 人。动画 00100020 按位置清塔，增援出生和 VoidCall 结束清全部塔，已处理对象不会凭旧快照重新产生。塔满/超员、补人数优先、预测伤害和个人输出均迁入 MP。

雷达通过独立三角网填充和裁剪多片场地/孔洞，真实轮廓只用于边框；世界边界保留全部外环和孔边。裁剪用边距容差处理投影误差，防止三角接缝漏判和旋转边框截断。危险区显示维持真尺寸，导航余量只应用一次。

新增录像帧字段 `LegacyMovement`、`CameraAzimuth`，增量帧也记录。旧录像缺字段时使用标准移动默认值；缺少相机的传统移动帧不伪造滑行落点。MP 回放仅规划和绘制。
