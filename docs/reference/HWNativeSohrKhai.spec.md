## 双视图与恢复顺序

七个静态场地由解析后的运行库多边形导出，仅保留 MP 数值几何；Poqhiraj 256 种墙组合在 MP 构造并集外环。雷达与世界绘制共用生产预览，导航区独立注册并禁止重复绘制。范围用原尺寸显示，普通危险的躲避余量仅应用一次；击退、薄冰及墙后补集保持精确可行域。

回放帧中的历史 EAnim 在恢复读条前应用。否则同帧包含旧墙事件和新击退读条时，墙后安全快照会错误地看到八堵完整墙。重复桥/墙状态不重建同一边界，避免逐帧清理与重新注册。
