# 邂逅篇原生迁移

当前实际接管 T01 ADS/卡杜凯乌斯、T02 ADS 与六节点、T04 Gauntlet、T05 双塔尼亚，共十一个源模块。入口分别为 `Presets/Raids/Entries/Coil1.cs`、`Coil2.cs`、`Coil4.cs`、`Coil5.cs`；生产实现不创建 BMR 模块或会话，不引用 BMR 类型。卡杜凯乌斯及双塔尼亚的机制、显示与个人导航已经实现并离线验证，但源敌人坦克元数据和逐目标禁DoT尚有接口缺口，审计保留 `mp_script_needs_parity_review`，不标为完整迁移完成。

## 身份与启动

本机客户端 `ContentFinderCondition → TerritoryType → ContentFinderCondition` 往返核对：

| 内容 | CFC | Territory | 主 OID |
|---|---:|---:|---|
| T01 ADS | 93 | 241 | 0x887 |
| T01 卡杜凯乌斯 | 93 | 241 | 0x7D7 |
| T05 双塔尼亚 | 97 | 245 | 0x7E5 |
| T02 ADS 与节点 | 94 | 242 | 0x7D9–0x7DF |
| T04 Gauntlet | 96 | 244 | 0x1E86F9 |

T01 按主 OID 分别接管 ADS 与卡杜凯乌斯，两战之间清理输出。T02 节点只在没有任何 ADS 处于战斗时启动，已启动节点不会因为 ADS 后来进入战斗而被强行退出。ADS/节点的单死亡阶段按主对象死亡、移除或 HP0 结束，不按同 OID 全灭结束；普通脱战和个人死亡不替代阶段结束。Director 团灭 0x40000005 清场并门控重开，0x40000011 解除。

## T01 ADS 与 T02 节点

场地矩形以源半宽/半长转换为 MP 完整尺寸，含 T01 14×56、T02 主场36×26、检疫28×26、攻击34×34、卫生36×30、监视34×30、防卫34×28、处置28×40。节点能力逐项隔离，不根据吞节点动画推测技能解锁。

- 高压电流1447/1216显示打断提示；按职业选择现有打断技能，执行复核当前真实读条及可打断标记，受智能走位开关和回放门控。
- 排斥炮R8.3；T01污浊炮R5.15；激光前长32.3/宽6；Firestream前长35.5/宽6，所有真实 helper 读条独立显示与导航。
- Ballast三段为R5.5扇形、5.5–10.5和10.5–15.5环扇，总角均270°。BMR参数为半角，MP参数为总角；定向回归逐点采样对照源几何。真实 Finish 只消费对应 helper，Effect不替代Finish，标称结束时间不自动清队列。
- T02顺劈使用同 OID 全部存活且可选中对象，主ADS R8.3、节点R7.15、总角120°。任意读条期间隐藏，结束后恢复；方向取敌人→当前受击者。受击者只显示轮廓，并按其他活队友方位注册R100引导禁区；其他玩家躲实际扇形。
- 重力场包含动态施法目标预测、Effect锁位置/+1秒、实际对象三路。实际对象位置量化，包含EventState7；每对象每次观察只消一个2码内预测。没有实体接替时预测保留到组件清理，与源缺口一致。

源没有 ChainLightning、VacuumWave、节点吞噬队列、1229准确狂暴倒数，也没有这些动作的伤害预测。生产不以枚举注释补造实现。

## 卡杜凯乌斯

主对象可选中且战斗中、当前HP严格大于最大HP的一半才启动，避免分身启动第二个阶段。分身在主对象HP不高于一半时锁定首个其他同OID对象，锁定后不换绑；分身未死亡、未移除且可选中才算有效。主对象死亡/移除且没有有效分身才结束，HP0和脱战本身不结束；个人死亡和主对象已移除时仍保留有效分身战斗。

- HoodSwing为R11、总角120°动态顺劈，两只蛇读条时仍生效；非目标躲实际扇形，目标按其他队友方向引导。只有主对象1208 Effect重置18秒倒数，分身不重置。WhipBack1209为R9/120°，取读条方向、真实结束清理。
- Regorge1210和Syrup1214分别预测R4，Effect按处理时钟延迟2.1/0.3秒；读条目标动态跟随，Effect锁定目标当时位置。实际对象排除EventState7并量化位置，每次观察每个来源只消费一个2码内同种预测；未生成时不按标称时间删除。
- 保留12个边长9的六边形、1个非规则八边形及13个真实高度，分别以边框绘制到雷达和世界。平台状态2激活，每次事件把公共期限重置为当前时钟+6秒，其他状态只撤销对应平台，不以超时自动熄灭。packet/raw使用0.5秒确认窗口。
- 5条高边按`当前Y+0.1<上层高度`启用零宽线段，精确线段相交交给原生栅格。平台外侧与高边使用持续禁区，避免玩家恰在线上时硬障碍的起点豁免跳过整个平台外侧。普通共边保持通行。9条有向跳边按实际XZ位移前探2.5码，反向、静止与近乎平行不请求跳跃。
- 客户端`GeneralAction[2]`核实为跳跃。通过FFCS `UseAction(GeneralAction,2)`执行，0.1秒节流；受智能走位总开关、MovementAllowed、当前角色存活和ARR/MP双回放禁止门控。停止、切人、关闭移动时清理节流和位移历史。物理跳台与GreenMove并行效果仍需实机确认。
- 前10秒不生成策略站位。发光时未分身的R2负责平台0激活组合，其他组合由R1负责；生成者进入激活平台并集内缩1码，其余人回避激活平台。无发光时，软泥目标按实际HP20%选择蛇外侧或蛇中心R2交付；OT在分身前73%靠近平台6，治疗在平台5、R1在平台8、仍处最高层的R2在平台0，均保留源反向禁区与激活时刻。
- 源分身选敌的3秒接怪窗口、正负5%血量差、30%后平权及MT/OT/第二组分工均已迁移。软泥选敌使用待结算伤害/治疗后的HP，20%不再优先攻击；投送位置仍使用实际HP。349钢鳞在分身前只降低选敌优先级，不作为护盾硬禁攻。

**源几何修正**：上游`Platforms.PlatformShapes`的顶点顺序与`SDConvexPolygon(...,true)`符号不一致，13个平台中心均被判外；其外部Distance还可能在边延长线上返回零。MP保留坐标和边表，按真实凸多边形内侧与半平面内缩计算；不复刻上述错误，也不声称逐点等同错误SDF。定向测试覆盖13个平台、普通共边、5高边阈值、9跳边和真实解算器跨平台路径。

`ForbidDOTs`、敌人期望朝向/位置及自动挑衅等AI元数据没有对应PR控制接口，尚未承接为自动执行，不能将普通选敌或文字提示当成这些行为。源Platforms在模块构造时激活，MP目前在卡杜凯乌斯战斗启动后发布平台，未声称支持开战前的自动平台导航。

## 亚拉戈病毒

`CoilScript` 提供八个实际队伍槽的分工，默认未设置。仅八种分工全部设置且互不重复时启用自动接毒，按 PartySlot 解析当前视角，不按职业猜测。

- Cast1218预测持有者，期限为真实Finish+15秒；Status333 Gain覆盖持有者与期限，334 Gain记录免疫期限。
- 距毒到期严格>7秒不接；恰好7秒开始按R1→M1→M2→H1→H2→R2选择第一名存活、非持有者、免疫到期严格早于毒到期的候选。免疫不要求现在已经消失。
- 持有者等待接毒者。接毒者使用真正的R2外侧危险区，按毒到期激活；其他人避R7圈，按自己的免疫到期激活。不是以普通安全区偏好替代反向危险区。
- StatusLose、到期、持有者死亡和1219 Effect不清最后持有者，也不撤销已记的免疫期限。全局倒数保留负值。持有者缺失时不发布个人导航。
- packet/raw确认保留0.5秒收敛窗口，缺失时长允许raw补足，持续不一致不会永久冻结。来源、参数、期限增长超过1秒均可重发Gain；对象移除仅清该对象观察缓存，重现回灌Gain，不清源按槽保留的历史。
- 源以危险队友marker表示持有者；MP另用不参与导航的R3轮廓表达持有者，雷达/世界共用，不作为伤害AOE。

## T04 Gauntlet

入口不要求战斗或HP；首个开始终端不可选中即启动。场地中心(0,0)，R25。波次条件成立可立即推进，未成立保留源 `Condition` 的预期+1秒超时；进入时间以实际推进帧重置，不一次补跑所有漏过的名义波次。

| 状态 | 真实条件 | 超时 | 进入时激活 |
|---|---|---:|---|
| 0 | 任一可选中Soldier或Knight | 62.1秒 | 无 |
| 1 | 任一可选中Dreadnaught | 61秒 | 无 |
| 2 | 任一可选中Rook | 61秒 | Rotoswipe |
| 3 | 可选中且存活的Dread/Soldier/Knight均存在 | 61秒 | GravityThrustPox |
| 4 | 上述三种加可选中且存活的普通Bug | 61秒 | 无 |
| 5 | 1258真实Effect计数；无后继 | 不以118.9秒退出 | EmergencyOverride |

前3个条件不额外过滤死亡；后2个要求存活。状态名中的数量与Rook并非实际条件，不按名称补造。首个开始或结束终端可选中时完成；正常销毁先从源 `Enemies` 删除，因此空名单不满足源表达式里的IsDestroyed，原生同样保留战斗。终端缺失、敌人死亡、个人死亡、BattleEnded不替代完成。

Rotoswipe为R11、总角120°动态顺劈，读条期间仍有效；保留非目标躲避、目标引导队友、轮廓及个人警告。车点名为前长50、宽100矩形，只为当前被读条目标的玩家输出，取车实时位置与读条朝向；真实取消即时清理，不被尚未更新的raw读条复活。源对Rook的任意当前读条生效，常规动作是1236/1237。紧急模式只计Effect，不虚构全队伤害预测。Dread集火优先级2、其余源敌人1。

## T05 双塔尼亚

场地为中心(-3,-6.5)、R31。开战要求主对象可选中且战斗中；主对象死亡、移除或HP0结束，个人死亡与普通脱战不结束。Director团灭清场并阻止旧对象立即重开。分工沿用八槽 `CoilScript`，战斗职业角色另按ClassJob解析，不能把M1/R1分工当作职业。

- 20个状态串联：P1、P2分别按当前拘束装置数量>0、>1推进，未满足时为1100秒超时；消失/重现必须等真实可选中状态，不使用3.1/62.7秒预期值当超时。六次俯冲各有独立“收到点名/真实效果清点名”状态，条件可提前满足，未满足按预期+1秒推进。P3小怪组件进入后保留到整场结束。以太失控后重建P4顺劈与死亡宣告计数；第三个拘束装置进入P5，末态没有名义100秒退出。
- 垂直下落前长20、宽12，动态朝向首领当前目标；初次6.5秒，真实1240效果后12.5秒。非目标躲避顺劈，目标引导队友之外的方向。死亡宣告1458开始即切换坦克分工、预测下次36秒；raw开始时间<0.25秒漂移不重复切换。计数只由1458效果增加，不用1241/1242真伤包替代。
- P2火球1452效果记录目标，4.5秒期限、R4绿色轮廓；1246效果清目标。火牢1451效果给2.5秒期限，仅目标292 Gain清理，不能按期限强制消失。个人火牢目标清普通危险导航后进入首领R1，同时保留公共顺劈/火球绘制。其他非当前坦按治疗/远程/随火球职业组，在首领朝当前目标±135°、距8处R2集合；伤害预测按同一职业组，排除首领当前目标。
- 俯冲1456效果冻结目标当时位置；首领位置实时、无读条时朝冻结点，命中1.7秒；有读条时用锁定方向及Finish。前长35、宽12，只有1247效果清目标；不因Finish先清，不按注释添加未实现的30码击退。
- 小蛇优先目标按最低EntityId，遵从源实际代码；首个大蛇348剩余严格<10秒或无状态才击杀该小蛇。小蛇HP1优先级0；其余按待结算HP30%决定软优先级。避让OT预测HP≤1、其他≤10%，R9参与导航，R8轮廓参与显示。PendingHP为当前HP加录制/实时未确认效果的HpDelta。
- 以太失控组件进入后6.7秒，全队伤害预测；非MT进距首领最近装置R2，MT逐个使用其他装置R2，与源逐圈反向禁区一致。1248效果或7.7秒超时退出，法系可请求Addle。
- P4旋风沿用源提前量0，在真实NPC读条结束才采样队伍R2预测，预测不显示；任何旋风对象出现均清预测，包括State7。实际旋风仅非State7，显示hitbox圈，导航为hitbox+1。骑士未点名时避R15，1251效果点名后转目标连线，并按职业请求减速/眩晕；无活骑士才清目标。
- P5液体地狱1457点名、每累计第5次670效果清目标，新点名不重置全局计数；effect+1.5秒R6预测，没有名义超时。真实地火非State7，2码内逐项消费预测。孵化1453点名、1256清；目标进排除首领脚下装置后的R2并集，副坦安全时进脚下R2截球。副坦分支命中但地火覆盖装置时不回落普通路径分支；其他人避全宽4的球→目标及目标→最近装置路径。默认避装置R5；液体目标额外避所有队友R6。全部连线/轮廓经共同可视化通道进入雷达与世界。
- 死亡宣告减伤按源WAR/PLD计数轮换，M1/M2牵制、法系昏乱；骑士控制按真实职业可用技能筛选。请求有有效期、每0.1秒最多成功一个，经PR动作执行器发送；移动总开关、MovementAllowed、当前视角本人、存活、目标有效、读条/动画锁及可用性门控，ARR与MP回放禁止执行。没有把坦克文字提示伪装成自动挑衅。

## 控制边界与验证

本批源没有gaze、通用停手/停走、物理/法术盾禁攻实现。T04源码明确忽略Knight/Soldier物理/法术防御，并允许AOE。未把这些源缺口描述为已经支持的禁攻机制；原有MP护盾禁攻仍通过 `Hints.SetActionRestrictions(forbiddenTargets)` 联动PR ACR，且不影响治疗/自保。

源敌人AI元数据 `AttackStrength`、`ShouldBeTanked`、`DesiredPosition/Rotation`、`PreferProvoking` 没有等价PR执行接口，旧宿主桥也未消费这些字段；本批仅将可表达的目标优先级、顺劈导航、打断执行与换坦文字迁到MP。不能把换坦提示称为已自动挑衅，不能把敌人期望朝向直接当玩家朝向。这些元数据仍是待承接能力，不计为新增伤害预测。

- `.tmp/halatali-verify/coil-regression.log`：`--filter=Coil`通过30组，其中节点21组、Gauntlet8组及已有Valigarmanda共享coil1组。覆盖源几何逐点采样、独立结束、传毒严格边界、三种状态同步边界、真实解算逃离危险区与资源清理。
- `.tmp/halatali-verify/coil-build.log`：主项目CI编译0错误，4条已有斗兽警告。
- `.tmp/halatali-verify/coil-smoke.log`：130个入口独立编译，全部原生地城/讨伐回放与新增实际DLL邂逅篇回放。新场景覆盖七节点、双视图、真实Status/Effect/Cancel、八槽设置、六波条件、终端移除、死亡、团灭/重开、反向Seek和owner清理。
- `.tmp/halatali-verify/caduceus-regression.log`：卡杜凯乌斯17组，含平台几何、真实寻路、克隆生命周期、待结算HP与跳跃门控；主项目编译日志为`caduceus-build.log`。
