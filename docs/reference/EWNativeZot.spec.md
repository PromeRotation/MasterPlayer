# 佐特塔 MP 原生脚本

入口：`Presets/Dungeons/Entries/TowerOfZot.cs`，GUID `masterplayer.dungeon.zot`。
客户端表核对 CFC 783 → Territory 952「异形楼阁佐特塔」。三名主对象分别为 33EE、33EF、33F1；三姐妹同时接管 33F2/33F3。生产只使用 MP 的 `DungeonEncounter`、安全区、绘制与脚本门面，不创建 BMR 模块。

## 源定义与时序

- Minduruva：保留辅助体雷 R3、毒 180°/R40.5、冰 20°/R40.5、火环 5–60。以实际组件尺寸为准，火环不采用枚举注释的外径 40。25244 开始后三次 25245/46/47 真实效果才清除连续伤害提示；读条结束不提前清理。
- Sanduruva：爆炸球按出生位置量化，首次出生 +10.8 秒，后续波 +20 秒。初始只绘制，首个球的 activation−7 严格小于当前时间后整组参与导航。25252 读条结束、取消、销毁施法者均清整组。已消费球的旧快照不复活。清理同时撤销待更新标记，避免上游在提前取消后访问空列表。
- 三姐妹：三者全部死亡或消失才结束。主对象死亡/销毁后更换当前对象，保留其他人的机制和场地。25281 后三次 25282/83/84 真实效果结束连续伤害提示；辅助体普通 AOE 与分摊/分散逐个按读条生命周期管理。25268 使用组件 R15，不采用注释 R40。球出生 +7.3 秒即参与未来危险规划，25279 cast-finished 清整组。
- 普通辅助体 AOE 按 Action 匹配，沿用源组件不限制 OID 的语义，覆盖 233C 与 3610。方向使用读条包朝向。三处场地由上游已经应用差集的多边形导出，雷达、世界转换和导航共用原生几何。

## 导航与控制

- 分摊目标本人必须靠向队友，其余视角进入目标圈；分散目标本人避开队友，其他人避开目标。原尺寸预览与带一次余量的导航分离，避免重复危险。
- 中毒 18 提供治疗职业与诗人的驱散目标，接入既有 PR Esuna/光阴神的礼赞执行路径；回放、关闭智能移动及宿主不允许移动时禁止执行。状态事件增删与对象快照均可驱动。
- 二王的无意义爆炸球不作为自动选敌目标，不转换成全局停手。三姐妹优先 Cinduruva，再 Minduruva，再其余目标。
- 上游没有启用盾禁攻或视线组件。Manusya Stop 仅保留施加止步的提示，Reflect 仅是未启用额外组件的视觉动作；不凭名称添加停手、移动锁或面向请求。
