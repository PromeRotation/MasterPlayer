# 无机制场地时的本地地形

没有注册场地时，MP 从游戏当前有效的碰撞场景提取几何快照，后台批量构建局部通行高度场，再发布不可变的 fallback boundary。通用躲避和目标跟随继续使用 MP 的时序寻路器，不把 AOE 时序规划交给外部插件。

## 场景快照与建模

- `NativeTerrainSceneSource` 仅在主线程提取数据。通过非阻塞 `TryAcquireSRWLockShared` 持有 `BGCollisionModule.UpdateTaskLock` 的共享锁，与游戏碰撞更新互斥；未获得锁或场景加载未完成时等待下一帧。只读场景，不修改碰撞体、不向游戏添加实体。
- 遍历 `Scene.Colliders`，只纳入 `VisibilityFlags & 1 != 0` 且 `LayerMask & 1 != 0` 的附近实例。Streamed 是容器，其当前加载的 Mesh 子碰撞体已在场景中，不重复建模。按当前有效碰撞体筛选，不能照搬 vnavmesh 为深宫地图生成而纳入未激活房间的特殊规则。
- Mesh 使用 FFCS `ColliderMesh` / `MeshPCB.FileNode` 的实际字段，复制节点树的原始与压缩顶点、三角面索引、材质数据；纯托管 `TerrainMesh.Decode` 在后台解析。快照只携带模型副本、世界变换和材质值，不把游戏指针或原生 Span 交给后台。节点索引、循环、数据范围和有限坐标均有检查。Box / Cylinder / Sphere / Plane / PlaneTwoSided 转为三角面，圆形实体采用保守的外接细分；MeshSimple 等未知格式明确报错并停止移动。
- 静态文件模型按资源路径与节点/三角面数量共享；`MemoryData != null` 或无资源路径的程序生成模型每轮快照复制并按内容 SHA256 复用解码结果，不能只凭指针和数量判断未变。同一次分帧提取暂存已复制模型，完整发布后清除暂存；同地址、同数量的顶点更新也会触发重建。复制模型以 1ms 为继续处理预算，至少允许完成一个新模型，单次复制不可中断，因此锁内总耗时并非硬性 1ms 上限。缓存约 128MiB 时淘汰本轮未使用的模型，当前窗口必需模型不被逐出；深宫同一静态资源的多个实例和换层复用无需再次复制、解析。
- 材质替换沿用原生规则：mask=0 时只使用三角面材质，否则使用 `(triangle & ~mask) | objectValue`；解析形状使用自身材质。通行建模不能以通用射线查询的 0x4000 位过滤几何，否则会漏掉不携带此位的活动墙门和隐形边界。保留当前有效 layer 1 几何；0x2000000 洞口与 `(material & 0x1F) == 0x11` 禁行边界不允许站立，普通 0x10 材质不作禁行处理。不能照搬离线导航提取时跳过条件门的规则，当前生效的门必须参与建模。
- 显式禁行面独立栅格化，再按支撑面及身体净空区间扣除通行跨度，之后执行角色半径腐蚀。仅将禁行面设为 Recast NULL area 不够：它与可走地面共面时，跨度合并会采用更宽松的区域，导致开阔场景边界或洞口重新变成可走。
- `SceneTerrainBuilder` 使用固定 `DotRecast.Recast/Core 2026.3.1` 在后台批量栅格化几何。XZ 分辨率 0.25m、高度分辨率 0.05m，法线 Y 至少 0.65；净空至少 1.65m、邻接跨高至多 0.65m。过滤低顶与悬崖边缘，再按 0.3m 角色半径向上取整为两个体素做通行腐蚀，不增加 AOE 余量。从实际支撑面附近的种子沿高度场邻接取可达区域，不把不相连的房间/上下层混成通行地面。
- `SceneTerrainModel` 先构建并发布 8m 近身区域，再补齐设置的 8–30m 范围；默认 20m。水平移动超过 4m 时以新位置拼接，仍在旧图内可暂时保留旧图。每 0.5s 提取附近实例状态；采集、比较及建模固定使用当前窗口的 anchor，不跟随窗口内每一步玩家位移，避免远处碰撞体进出裁剪范围被误认为场景变化而清空有效通行图。模型、变换与材质都未变化时保留同一边界和解算版本，不重复建模。真实几何变化立即将受影响块标为未知，保留其他已确认通路，再异步重建；取消、generation 及缓存 revision 检查保证旧楼层/窗口任务不能发布结果或重新填入已清理缓存。
- `LocalTerrainBoundary` 使用可达通行单元并集，复制标记与高度；轮廓保留外缘和内部洞口，不简化成外接圆或最大外轮廓。MP 的网格搜索、路径简化和平滑读取同一不可变边界。宿主仍是 2D 规划器：一个 XZ 列只能保存一个高度；相差超过 0.65m 的多个可达支撑面重叠时，该列保守地设为未知，不伪造层间连接。
- `SafeZoneManager` 独立持有 fallback boundary，正式机制场地优先；存在正式场地或处于回放时不采集实时地形。地形已经处理角色体积，fallback 额外场地收缩为 0；AOE 原始形状、MP 危险区安全余量与时间缓冲不变。

### 躲避中的地形发布

MP 正在执行通用躲避路线、GreenMove 仍运行且剩余路线全部被当前通行图覆盖时，因玩家移动产生的新窗口只在后台准备，不替换规划边界、雷达地图或导出快照，也不递增规划版本。近身图升级为完整图若恰好与逃离重叠，同样延迟发布。保留状态取决于实际已下发路线及 GreenMove 当前进度，不取决于候选解或整个 AOE 控制权保留期；路线完成后即可发布，不等全部 AOE 消失。普通跟随、无路线、宿主/回放门控、直接捷径和未覆盖的剩余路线不请求保留。

移动窗口刷新期间保留同一旧图直到完整候选就绪，避免近身中间图缩小正在使用的通行范围。躲避结束后，先按候选原始中心和半径重新提取场景，确认几何仍一致，再一次性发布完整图及其配套显示/导出快照；候选过时则丢弃并按变化后的场景重建，不恢复旧通路。

延迟仅针对可选换图，不延迟碰撞处理：等待期间仍每500ms复查**正在使用的旧窗口**，不能只检查新窗口，旧窗口内真实几何变化立即使对应规划块失效；行进前方逐帧原生复核、局部碰撞修正及恢复照常执行，修正不等待候选发布且跨发布保留。玩家离开旧图覆盖范围、支撑层变化、深宫换层/布局变化、查询异常或功能清理仍按原契约失效/撤路，待发布结果不能复活。

### 同层通行块缓存

`TerrainNavigationCache` 在当前地形会话内保留已构建的8m×8m块（32×32格），每块另外栅格化1m边带，避免块缝成为假悬崖。场景提取半径比规划窗口多8m，加上原有2m裁剪边带，保证窗口边缘涉及的整块与建模边带都有几何输入。只对缺失块或实例几何改变的块执行Recast；返回已建窗口不重复栅格化。分辨率、材质、净空、跨高和角色半径规则不变；高度量化按16m固定高度带对齐，构建器版本递增为2。

缓存保存每个格的全部有效支撑跨度、四向邻接目标高度及实体垂直区间，避免缓存某次玩家起点的单一可达房间。每次拼接从当前支撑面重新做可达搜索；跨块邻接必须双向一致，不能穿过墙门或切换到无连接的上层。发布边界仍不可变，显示历史仍不参与规划。

快照发现实例新增、移除、变换、程序模型或材质变化时，按变化前后世界包围盒及边带失效相关块，当前边界对应块立即标为未知，其余块保留；随后只补建失效部分。原生快照携带已读取的世界包围盒，主线程失效处理不解码模型；无法确认包围盒时保守清理全部通行块。局部失效期间暂停场景导出，避免将混合状态当成完整可重建快照。切区、深宫director/楼层/布局、支撑层变化、关闭及完整清理丢弃通行块；战斗结束保留，同一静态模型资源仍可跨层复用。

## 实时碰撞复核

`NativeTerrainRaycaster` / `GameTerrainProbe` 继续用于实时找地与路线复核，生产地形建模不调用逐格 `Sample`。旧 `LocalTerrainScanner` 仅保留作解析对照、原有回归及性能基线，不是场景建模失败时的自动降级。

新路线首次下发前，以及 MP 持有移动控制权期间的每帧，从实际支撑地面检查前方至多 2m：以不超过 0.3m 步距确认地面和头顶 1.65m 净空，在两个身高和侧向 0.3m 宽度复查身体通道；身体射线额外向前检查 0.3m 角色半径，避免目标点在墙前但身体已经接触墙体。共线段合并身体射线但保留所有地面样本。沿用 FFCS layer 1、材质 0x4000 原生射线；缺失法线时测量周围支撑高度，不能把零法线直接判作陡坡或平地。原生复核允许上升至多 0.65m、下降至多 0.8m，建模邻接使用较保守的 0.65m 跨高。

连续缓坡按当前位置的缓存地面比较，不以扫描中心旧 Y 坐标重建；实际支撑面与缓存相差超过 1m 时换层建模。`Jumping` / `Jumping61` 期间保留地图并暂停提取/发布，落地后继续；无标记但离地时仍可用缓存支撑面投影。初始化正跳跃则等待落地，不从空中生成悬崖图。

前方关门或支撑消失时，只撤销 MP 自身路线。场景模型路径中若取得真实受阻位置，`TerrainCollisionCorrections` 将其按角色半径局部扣除，发布供寻路与雷达共同消费的新不可变边界；不再只重建相同场景而反复恢复同一错误通路。墙体取最近原生命中点，缺失支撑取失败地面位置；修正按支撑高度区分楼层，不修改 AOE 或正式机制场地，也不全图逐格采样。修正同层跨局部模型重建保留，远离当前窗口时保留但暂停原生复核，回到附近确认恢复通行后才移除；切区/深宫换层/完整清理时丢弃。

每个修正至少间隔 500ms 重新复核原来的受阻短段，一帧最多复核一处；确认恢复通行才移除，受阻位置改变则更新。没有变化时保留同一边界和解算版本，门打开后可恢复通行。查询异常或未取得具体受阻位置不凭空制造墙体，改为失效地图、停止移动并重试；不停止其他来源的 GreenMove。未就绪、未知和建模失败都不可通行，不退回无限制平地；异常显示完整原因并间隔 2s 重试。关闭地形功能才恢复原来的无地形规划行为。

## 生命周期与显示

`EnableTerrainCollision=true`、`TerrainScanRadius=20`、`RadarShowTerrain=true` 随 `MasterPlayer.json` 持久化；旧配置缺字段时使用默认值，不新增模式开关。诊断页显示快照/结果发布的本帧耗时，状态文本单独显示最近后台构建耗时和同层缓存块数；前者不含实时找地/路线复核，后者不是主线程阻塞时间。只关闭显示不影响规划。

雷达使用灰色表示身体高度范围的阻挡，橙色表示落差、陡坡或未连通的支撑区域，白色线表示已确认通行区域的外缘和内部洞口。连续同类阻挡按行预先合并为矩形，绘制不逐格遍历细网格。无脚本但启用地形显示且有局部图时仍显示雷达；真实世界绘制不绘制本地图。没有有效通行区域时明确显示未找到地面，不宣称模型正常可用。

雷达显示地图与规划地图分开：初次构建可先显示近身图；已有地图后，刷新、开关门或移动窗口重建期间保留上一份完整显示地图，完整替代结果就绪后整体切换，不用近身中间结果缩小旧图。雷达比例固定使用 `TerrainScanRadius`，不读取当前近身/完整网格的实际宽度。保留的旧图只用于地形绘制，不注册到 `SafeZoneManager`，不用于路径、AOE、安全判断或原生复核；规划仍在检测到场景变化时立即失效旧通路，再发布新近身/完整边界。建模失败仍禁止移动，允许保留显示历史；切区、深宫换层/布局变化、支撑层变化、关闭功能及正式机制场地接管时清除旧图。

无当前玩家、死亡、停止会话、切区和显式完整清理安全区均丢弃地图。战斗结束只清理危险区、目标区、机制场地和移动请求，保留局部地形，避免深宫每打完一只小怪就重新扫描。主线程通过 FFCS `EventFramework.GetInstanceContentDeepDungeon()` 读取深宫 director、`Floor` 和 `ActiveLayoutIndex`，身份变化立即丢弃旧图；同一区域、相同坐标的换层和镜像布局切换也不能复用旧图。

ARR 与 MP 离线回放不查询实时地形，不以当前游戏碰撞场景覆盖录像场景。当前录像格式没有地形数据，因此离线回放不能复现这份实时地形地图。

## 验证与限制

### 真实场景导出与阶段耗时

- 主面板「诊断」→「地形场景诊断」→「导出地形场景」保存最近一次已完成并发布的近身或完整建模快照。显示采集 UTC 时间、实际构建半径；未完成首次建模时按钮禁用。此动作只读取托管快照，不重新访问原生场景、不启动移动、不改导航结果。
- 目录为 `ConfigDirectory/MasterPlayer/TerrainCaptures/`，文件名为 `terrain_<UTC>_t<区域>_<随机ID>.terrain.zip`。后台写临时文件，完成关闭后再发布最终文件；文件名唯一且禁止覆盖，失败显示完整异常，不传播到地形更新。已经请求的导出在换层或清理后仍保存请求时固定的快照。
- 归档 v1 包含 `manifest.json`、`geometry.bin`、`base-map.bin`、`published-map.bin`。清单记录采集时间、区域/深宫层与布局、支撑原点、半径、构建器版本与参数、导出程序集 MVID、采集和构建阶段诊断，以及当前局部碰撞修正。二进制几何按模型对象去重，保存解码后的顶点、三角面及完整 64 位材质、实例变换和材质覆盖值/掩码；程序模型同样保存实际几何，不依赖 SqPack、原生地址或游戏进程。通行图保留各格类型及高度，基础图与修正后的发布图分别保存。
- 离线重建：`dotnet run --project tests/TerrainCollision/MasterPlayer.TerrainCollision.Tests.csproj -- --terrain-scene "<归档绝对路径>"`。程序调用生产 `SceneTerrainBuilder`，逐格比较基础图和应用已记录修正后的发布图，输出 `BaseMatches`、`PublishedMatches`、原始/重建阶段耗时及几何计数；不一致或文件损坏返回非零退出码。归档格式、构建器版本或固定构建参数不同则拒绝加载；改变构建语义时须递增 `SceneTerrainBuilder.VERSION`。导出保存的是已解码几何，因此离线模型解码成本不等同于首次原生 PCB 解码成本。
- 采集诊断区分总耗时、锁内耗时、模型字节复制和程序模型内容哈希，并记录遍历/纳入实例数、网格缓存命中、本次复制/哈希模型数和字节数、原始模型缓存字节数。诊断页分别显示最近一次尝试和建模输入的多次尝试累计；归档保存建模输入累计，避免分帧复制的前几帧成本丢失。累计的纳入实例与缓存存量取最后一次，其余工作量和阶段耗时相加，不包含帧间等待；未完成提取时明确标记等待补齐。
- 后台构建区分模型访问/解码、世界顶点变换、面分类与窗口裁剪、光栅化、低顶/悬崖过滤、紧凑高度场、显式禁行扣除、身体半径腐蚀、可达区域提取、不可变边界生成。记录实例顶点/面总量、实际栅格面、禁行面、紧凑/可达跨度及通行格数。总耗时还包括初始化及少量阶段间开销，不含排队、主线程采集、结果发布或实时路线复核；原始采集诊断与建模快照同时固定进归档。
- 通行块缓存增加 `BuiltTiles`、`CachedTiles`、`StoredTiles` 诊断；栅格化阶段及面计数只统计本次实际构建工作，完全命中缓存时为0，可达搜索与边界生成仍运行。归档继续保存发布图对应的完整场景与当前实际工作量，离线从空缓存重建，图形应逐格一致，工作量无需相同。专项测试覆盖归档往返及重建、共享/程序模型、64位材质、镜像变换、高度与碰撞修正、格式/截断拒绝、异步导出失败、快照代际清理和阶段计数。

设计参考 vnavmesh 的 [SceneDefinition](https://github.com/awgil/ffxiv_navmesh/blob/master/vnavmesh/SceneDefinition.cs)、[SceneExtractor](https://github.com/awgil/ffxiv_navmesh/blob/master/vnavmesh/SceneExtractor.cs) 与 [NavmeshBuilder](https://github.com/awgil/ffxiv_navmesh/blob/master/vnavmesh/NavmeshBuilder.cs)。MP 直接读取当前生效的 BGCollision 几何，使用 Recast 高度场和自身时序规划器；不依赖 vnavmesh 插件或其 IPC，不生成全地图飞行网格。DotRecast 的 DLL 与许可一起部署，许可见 `ThirdPartyNotices/DotRecast.LICENSE`。
