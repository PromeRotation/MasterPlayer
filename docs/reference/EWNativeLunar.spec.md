客户端CFC823对应区域1164「异界深渊月面地下溪谷」，入口`Presets/Dungeons/Entries/LunarSubterrane.cs`，GUID `masterplayer.dungeon.lunar`。接管上游D13的DarkElf(3FE2)、DamcyanAntlion(4022)、Durante(4042)三个模块。生产不实例化BossModule或机制桥会话。

## Dark Elf

模型状态元组变化且魔杖3FE3的AnimationState2为1时追加40码、半宽4十字，位置量化、朝向快照。初次启动只建立模型基线，源码激活组件也不回灌模型状态事件。35205真实结束次数分别决定8.1、25.9、32秒延迟。首项时间减5秒严格小于当前时间时，全组才参与导航，之前仍填充绘制。任意34787矩形读条存在时，整组十字暂时隐藏，缓存保留。35254/34789真实结束清全组，34783视觉不清。

34788分散半径6、导航半径7；35204单体死刑、34782全屏伤害。SID3364通过事件和状态快照跟踪驱散，职业和实际执行沿用MP脚本门控。34778仅在源码枚举中出现，没有护盾禁攻实现，不凭技能名增加状态判定。

## Damcyan Antlion

初始场地半宽19.5、半高25。34813开始预告旧边界减新边界条带；读条结束不缩场，map00/00020001才缩至半高20并清预告。

34819为事件朝向的前40码、半宽5作用区，向前击退20码。自定义导航危险条带为场地长度的最后20码，初始长度50、缩场后40；免疫不取消这项源自定义导航。个人落点显示受免疫有效期和作用区门控，多来源按列表依次累加，不遇墙截断；危险落点包括任何倒塔范围，即使倒塔尚不Risky。

每个34819真实结束清除全部击退来源并增加累计次数，第5次起倒塔危险。map任意index>0/state00020001按源码左右公式追加倒塔，无去重或上限，时间为事件时钟加13秒减追加前数量。恰有两塔且存在击退时，Z差四舍五入为10或30要求进入至少一个条带，否则避开两条；使用首项击退时间。34820效果清塔及危险标志，不清累计次数。

35871建立宽9冲锋，起点量化、长度/朝向使用未量化原始差向量，时间Finish加4.2秒。全部填充并参与导航，多项时首项黄色且颜色持久；34817效果推进FIFO。流沙OID1EB90E半径10硬障碍，只根据第一对象EventState是否7门控全组，包括dead对象。34822为半径10四人硬分摊；候选聚合、观看者颜色及点名靠拢排除其他标记者。

## Durante
