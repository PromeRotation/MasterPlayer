# 玉韦亚瓦塔实验站 MP 原生迁移

区域 1242、CFC 1008（本机客户端表核对），入口 `Presets/Dungeons/Entries/YuweyawataFieldStation.cs`。三个首领与六组道中全部使用 `DungeonEncounter`、MP 本地几何、安全区和脚本输出，不实例化 BMR 模块或会话。源为 `MechanicRuntime/Upstream/Modules/Dawntrail/Dungeon/D09YuweyawataFieldStation/`。

## 时序与场地

- Zaghnal 的 LineVoltage 保留输入顺序，首项时间加 1.5 秒为严格 `<` 批次界限；当前批次才参与导航，已晋升的危险标记和颜色不回退。按施法者消费首个匹配项。CellShock 由地图事件预测，8 秒后生效，电压队列存在时隐藏；反转索引及未识别索引回落原点保留源行为，40626 结束才清除。
- Kanilokka 的 Soulweave 使用同样的持续晋升语义，窗口为 1.3 秒，结束事件按 FIFO 消费。Dark II 从第 12 项开始排序，只输出前六项。地图索引 7 的五个状态切换完整精确场地；FreeSpirits / PhantomFlood 显示缩场预告，确认地图事件才更新边界。
- LostHope 的准备状态在读条开始建立，结束不清；任意索引 7 地图事件撤销。准备阶段发布中心半径 1、权重 9 的软目标。1422 / 2936 / 3694 / 3909 按状态 Gain / Lose 更新角色误导掩码，失去其中任何状态均清该角色掩码，与源组件相同。
- Lunipyati 的怒爪保留至累计第六次实际命中，落石保留至第 30 次实际命中；读条结束、时间流逝不替代实际事件。CraterCarve 始终显示，剩余 2.5 秒时才参与导航。BeastlyRoar 同时提供 R25 范围和全屏伤害预测。
- LeapingEarth 小图案凑齐四个视觉读条后以第四次事件时钟加 6.5 秒、每点 0.2 秒生成；保留原始弧度和的整数截断分支与特殊 intercardinal 常量。大图案以视觉开始加 4.5 秒、间隔 0.25 秒生成二十点，显示前十；真实 40606 仅消费 FIFO，不重复创建圈。
- RockBlast 只在队列为空时以施法者位置和源 cardinal 常量判方向，生成十五圈、间隔 0.6 秒，显示前八；任意对应读条结束消费 FIFO。旋转矩阵遵循源世界点旋转，未误用 FFXIV 朝向增加方向。
- JaggedEdge 在怒爪存在、原始分散队列非空且本人不是原始点名目标时，以 Boss 身后深 1 码、左右各 50 码的区域替代分散 AI。目标死亡仍保留原始队列条件，绘制按存活目标处理。
- 十五种场地通过离线导出源解析后的多边形得到，包含六组长走廊、首领起始切角、五阶段路径和最终环形场地。雷达、世界绘制及规划消费同一本地几何。

## 生命周期、输出与控制

- Bat / Researcher / Phoebad：无范围开战、方形范围内存活成员阻止结束；Woolback / Specter / Golem：方形范围内开战、所有存活成员阻止结束。范围为源 Bounds.Radius 的方形包围范围，非精确多边形。首个主怪死亡或脱战不提前结束整组；共享 OID 按场地距离及开战范围选择组。Bat 重复 46A3、未列 4610 的源列表不擅自修正。
- 读条修正按同一 Source / StartedAt 更新简单范围、批次、目标、怒爪、落石和螺旋几何；保留已消费项、批次颜色和原始激活时钟。分散/分摊目标缓存最后观察到的移动及死亡状态，销毁后不回到起始快照。
- 分摊采用 6 码轮廓、4 人上限、3 码目标聚拢半径；满员且本人在圈外或超员时避让。绘制依本人目标身份、是否在圈内及人数使用安全或危险轮廓。各动作的独立源组件分组保留，不混用不同机制的目标掩码。
- RawElectrope 保留优先级 1，其他目标为 0。该区域源没有护盾禁攻、视线或专用停手机制，不额外创建限制。
- 误导执行复用已有副本原生输入控制：必须持有 MP 移动控制、有 GreenMove 当前目标、智能移动及 MovementAllowed 开启、没有 PR 本体控制；手动输入优先。回放、切区、过场、死亡、关闭移动或 owner 失效撤销。输入签名和箭头访问路径沿用已核对的 Vanaspati 实现，没有新增原生地址猜测。
