# EW 普通讨伐 MP 原生迁移

生产入口位于 `Presets/Trials/Entries/`，状态与几何位于各自同名目录，通过 `DungeonScript` 的本地安全区、绘制及控制门面执行。生产实现不创建 BMR `BossModule` 或 `MechanicSession`，不保存 BMR 值类型。本文描述本仓实际提供的 T02、T08 源码；缺少源码的其他 EW 普通讨伐不在覆盖声明中。

区域经本机 CN 游戏 Lumina 严格表校验并双向核对：海德林 CFC790 ↔ Territory995，阿修罗 CFC944 ↔ Territory1136。合成回放用于接口与生命周期验证，不是 ARR 实录或实机验收。

## 海德林

入口 `masterplayer.trial.hydaelyn`，主对象 0x34EA。单个 TrivialPhase 同时启用15个组件，主对象死亡或销毁结束；水晶阶段不另建会话。个人死亡保留全场历史并清个人执行控制。场地是中心100,100、顶点半径20的正48边形。

- 武器 SID2273 Gain：0x1B4 为场地中心量化 R10、0x1B5 为5–40环，回调起钟+6秒，覆盖一个预测；未知 Extra 保留旧预测。Lose 为该对象当时量化位置、朝向的臂长40/半宽5十字，+6.9秒。26255、26055、26056实际命中清除，时间不消费。快照同来源/参数、到期延长≤1秒不重复Gain，延长>1秒才重启；来源变化先Lose后Gain。显式事件与快照按身份/参数/来源收敛，允许到期时间采集误差；0.5秒后仍未收敛由快照纠正，避免永久屏蔽后续变化。
- 幻日环由六角1EB24C Created追加中心与R17六点，三角1EB24D追加R8三点；各自回调+7.6秒、R6。方向端点先量化再按源码浮点角度旋转；对象移动、死亡、销毁、时间均不消费。任意26061 CastFinished清全部，未启用的普通 Incandescence R6 组件不添加。
- 回声 Icon305 使用 actor，忽略 targetID，追加R6、8/8分摊，+5秒。26065无论集合是否为空都累加命中，恰第5次清全部并归零，前四次不续期。死亡目标仅隐藏，复活恢复。保留人数与点名重叠提示、进入分摊/远离满员圈导航。
- 光波由26058命中捕获 caster 引用，同代际去重；前16、后12、半宽8动态矩形，每次输出now+1.1秒。死亡仍跟随；销毁冻结旧引用，不移除。相同ID新对象建立新代际，无需中间空扫描，旧光波不会重绑定。
- 出离严格按0x34EC水晶的第6次销毁建立+7.2秒全队预测，单纯死亡不计数；显式销毁使用事件时间。26066清除，第7次以后不重启；27911无分支，时间不清理。
- MousasScorn26070：R4目标中心共享坦克死刑，单状态覆盖；全部Tank角色预测，即使target解析失败仍保留source预测。目标避开非坦克、其他坦克进圈、非坦克出圈；坦克轮廓、其他坦克安全色、非坦克填充。源对象的有效读条结束清状态，迟到/被拒绝的结束事件无副作用。
- HerossSundering26069：源中心R40/全90°动态死刑扇形，显式Tankbuster预测，允许死亡目标，正常读条结束消费source首项。
- 水晶土27737为R6、8/8分摊；冰27738为R5分散、R6导航。两组件互不合并，结束按cast target删首项。源码两者 `RaidwideOnResolve=false`；Echoes虽为true，默认全员mask分支也不发布Shared预测，故均不补造连续伤害预测。
- Beacon1 26062按未量化的源位置→落点差求长度与方向，仅量化源起点，半宽3；Beacon2 26063前45/半宽3，只取前10项，cast落点不额外量化。HydaelynsRay26060总宽30、前45，采用实际代码参数，非枚举注释width40。
- 26071、26072、26064只提供读条全屏提示与全队预测，无几何。主对象与所有存活可见水晶输出敌人轮廓，水晶采用源默认Object色。启用链没有视线、强制朝向、护盾禁攻、停手或移动锁，不由枚举/目录能力标签推导执行。

定向回归 `tests/HydaelynRegression.cs` 包含25组且已通过，覆盖上述状态、时序、代际、延迟取消、输出精确几何与危险余量分离，以及圈内七人时对圈外第八人的提示和忽略高度的平面计数。实际 DLL 合成场景位于 `tests/ScriptCompilation/NativeTrialReplayHydaelyn.cs`，覆盖跨事件通道、个人死亡、反向Seek、停用和回放禁止PR执行。

## 阿修罗

入口 `masterplayer.trial.asura`，主对象0x409B。单个 TrivialPhase同时启用22个组件，主对象死亡/销毁结束，个人死亡保留历史。初始正32边形顶点半径是 `19.5f * 1.004839f`，约19.59436；`CosPI.Pi32th` 的实际定义是余弦倒数。地图index1/state00020001切为顶点半径19.165的正32边形。

- LowerRealm36001在初始场地建立19–20环形缩场预告，cast finish+0.8秒；不由cast结束或时间消费。地图切场清除，缩场后再施法不重新建立。36001与35990另有独立全屏读条预测。
- 六连斩由36011/36012/36013实际读条追加源落点/朝向快照，R20全180°，activation=cast finish+11.9f秒。仅暴露队首两项；首项在多项时改Danger色，第二项与首项反向误差≤1°时继续绘制但不参与导航。Risky与Color按源码写回队列；第二项升首恢复Risky，Color不随意归一。队列>1时另有进入首项原点R3的导航约束。35977–35982任一命中FIFO删一项，与source/target无关。没有按时间、telegraph结束或图标消费。
- 幻影爆炸：任意对象timeline11D6追加其量化位置R9，事件时间+7.1−0.5×当前队列长度秒；对象死亡/销毁、时间和35991命中不消费，任意35991有效CastFinished清整批。事件时间扣除派发延迟沿用MP脚本契约，源使用处理帧CurrentTime，此处两者在延迟输入下会有对应时差。
- ManyFaces在六个实际脸谱读条时覆盖一个R20半场，使用源固定角180°、−0.003°、89.999°，与cast朝向无关，cast finish+0.1秒；仅36006/36007实际命中清除，cast结束与视觉事件不消费。
- MyriadAspects36020/36021共用队列，只取前6；收到第12项起才按activation排序，之前按插入顺序。有效结束按caster删除首项；旧时间/不匹配的取消事件不能提前删除当前输出。
- 脉轮实际源码映射：35994 R5；35995 6–8环；35996 9–11；35998 12–14；35997同时产生15–17和18–20两个独立组件。35999没有启用组件监听。此处保留源监听冲突，不用枚举名称或注释擅自修正。
- 普通/巨型台座为R10/R60，轮为8–40/48–96环；直线前50全宽6/前100全宽28；散射前20全宽6，均各自CastFinished结束。
- CuttingJewel36000为动态目标中心R4死刑，允许死亡目标，Tankbuster预测，结束按source消费。OrderedChaos36003为目标R5轮廓/R6导航，仅目标死亡隐藏，施法helper死亡不隐藏；复活恢复，结束按cast target删首项，不发布伤害预测。图标342/139及454–459没有已启用的额外处理分支。
- 启用链没有视线、强制面向、停手、护盾禁攻或移动锁。危险范围与R3站位约束通过MP本地规划器执行；所有世界和雷达预览经同一owner门面发布，停用清除边界及区域。

定向回归 `tests/AsuraRegression.cs` 包含15组，覆盖连续队列、风险/绘制分离、真实起始常量、地图切场、源监听冲突、目标/施法者死亡及迟到取消。实际DLL合成场景位于 `tests/ScriptCompilation/NativeTrialReplayAsura.cs`。

海德林和阿修罗均已通过当前实际 DLL 的120入口独立编译及全原生地城/讨伐合成回放；此为离线验证，仍需录像与实机确认。

## 验证边界

离线验证不能证明实时PR执行和游戏内最终呈现。两场均未使用ARR实录做预测延迟校准；源没有的光波LOS、水晶优先攻击或控制能力未补造。世界与雷达颜色使用源默认值，不读取BMR用户自定义配色。部署与游戏内重载未执行。
