# 雾之迹 MP 原生实现

区域 `1314`，CFC `1064`，入口 `masterplayer.dungeon.mistwake`。源依据为 `MechanicRuntime/Upstream/Modules/Dawntrail/Dungeon/D12Mistwake/`。三场使用 MP 事件、几何、绘制和规划，不创建 BMR 模块或会话。

- Treno Catoblepas：初始半边长19.5方场减13个16边岩石；map07–13不筛state，按源坐标容差删除静态岩石。模块激活时捕获的岩石Actor列表单独用于遮挡与保护，销毁移除，地图不删除Actor，后来创建不加入该列表。
- 43330视线遮挡：使用最早结束的存活施法者LocXZ、当时岩石位置与hitbox冻结阴影。每个阴影内半径为距离+.2，外半径30，半角asin(hitbox/距离)，弧线采用源.05近似误差。阴影并集绘安全区，其补集参与规划；施法者集合与安全区FIFO分别维护，乱序Finish不会把已结束施法者用于后续阴影。
- 43329目标死刑半径4，self目标回退施法者Target；个人引导避开全部岩石hitbox+4。43333分散显示5、AI6，只保护中心不在43332地面圈内的岩石，个人避hitbox+5。Icon524为+6.2秒、前50半宽2.5线分摊；目标按源码靠拢队友2码，避开朝向岩石的射线扇形。43334按实际目标消费，单条允许实际目标纠正，不按通用FIFO消费。
- Amdusias：45337/42总300度扇形；45345 BioII为全屏伤害，不创建R20圈。45353三击分摊在首击Finish后保留，第二个唯一45354效果事件清除，目标死亡不重置命中计数。普通读条分散死亡仅过滤、复活恢复，Finish按目标删首；这类源组件默认不发布伤害预测，三击分摊受allmask保护也不发布Shared预测。
- 45348连续冲锋：冻结起点及目标方向长度；激活为自身Finish+8.7+.5×追加前队列数。45347实际效果FIFO消费，剩余大于1才将新首项染危险色。读条结束、时间经过均不消费。
- 状态2536：任意Actor Gain在量化位置生成+4.5秒R9爆炸；快照恢复与事件确认去重只在本轮状态内生效，Lose或快照消失清确认计数，不吞下一轮Gain。45349 Start不建圈，Finish FIFO删首。所有预测公开，首项+1秒严格前缀按源码染危险色。
- Thundergust Griffin：初始场地保留入口缺口；45291仅生成Finish+.7的20–30月环，map17/20001才按源Arena.Center缩为R20正64边。45302 Rush存续时隐藏所有45304 Force的显示及导航；恢复沿用原激活时间。
- ShockStorm 4A67按创建时刻+6冻结量化位置与朝向，新Actor覆盖单条预测，后续移动和销毁不清，只有45299 Finish清除。创建事件可补正时刻。
- 47022：每条读条生成旋转±90度的两个半场定向击退12码。AI按最后一条方向的1度轴容差决定X/Z轴，以首条激活时间门控免疫，限制落点于解析R19圆；绘制逐条检查免疫并按更新后位置继续判断后续半场，避免首条免疫吞掉后续非免疫预览。任意该技能Finish清全部。

本区域源模块没有额外面向视线、护盾禁攻或停手机制，不从技能名称推断。雷达、世界显示及规划共享 MP 几何，个人输出使用统一观看角色和模拟时钟。

验证：`tests/MistwakeRegression.cs` 39项通过，包括岩石差集多组合与源几何逐点、雷达裁剪、世界转换、全部普通形状、连续时序、状态确认跨轮、乱序LOS、死亡复活及逐次免疫；最终普通分散伤害预测修正另有定向复测。`NativeDungeonReplayMistwake.cs` 通过实际DLL三场合成回放、事件路由、双视图数据、规划、清理及Seek重建。主项目构建及96个内置入口独立编译通过。
