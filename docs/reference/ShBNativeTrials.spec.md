# Shadowbringers 普通讨伐 MP 原生迁移

本批从运行库 `Modules/Shadowbringers/Trial/` 的真实启用组件迁移到 `Presets/Trials/`。原生脚本继承 `DungeonScript`，由 MP 管理事件、时钟、绘制、安全区、PR 面向与 owner 清理，不创建 BMR 模块或机制会话。下面的离线证据不等于 ARR 实录或游戏内验收。
