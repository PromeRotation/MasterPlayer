## 使用方式

- 按Boss中文名、英文名、NameID或Action ID搜索；程序读取[catalog.json](catalog.json)。
- [来源索引](sources.md)保存文章与分P视频链接；[待核验项](pending.md)集中记录缺口、差异与旧资料冲突。
- “官方展示”只代表副本选怪面板列出的技能，通常每个敌人最多两项；不是完整技能循环。
- “代码关联”表示当前组件、显式映射或枚举记录提到该ID；不是新确认的施法者归属或机制正确性。每条关联保留文件和行号。
- 源码参考形状使用原参数：Circle为半径；Donut为内/外半径；Rect为长度/半宽（可带后伸）；Cone为半径/半角；Cross为臂长/半宽。表内“—”不代表无危险。
- 客户端CastType、EffectRange、Omen、表读条只作参数线索。读条结束、伤害判定、点名锁定、物件出现与清理须另查ARR；CastType=1也可能是危险机制前置。
- 中文图文攻略已读文字；视频仅收集简介与分P目录，未观看画面或字幕。攻略中“伤害高可跳过”“突进抵消击退”等队伍策略不能直接代替通用走位规则。
