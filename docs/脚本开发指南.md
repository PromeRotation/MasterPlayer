# MasterPlayer 机制脚本开发指南

本指南面向想为 MasterPlayer 编写机制脚本的开发者。MasterPlayer 是运行在 PromeRotation（PR）之上的机制脚本框架：把单个 `.cs` 文件放进脚本目录，插件用 Roslyn 动态编译、热加载，按副本区域自动启停，单个脚本的编译/运行异常不影响其他脚本。

- 插件本体：`MasterPlayer`（PR 子插件）
- 脚本形态：单个 `.cs` 文件，继承 `MasterPlayerScript` 基类（也支持编译好的 `.dll`）
- 简单读条机制可通过面板「脚本」→「可视化编辑器」配置，生成 `*.mechanic.json`，与 C# 脚本按独立 GUID 并行运行；使用与扩展说明见 [可视化脚本编辑器](可视化脚本编辑器.md)。
- 脚本目录：`%AppData%\XIVLauncherCN\pluginConfigs\PromeRotation\MasterPlayer\Scripts\`
  （即 PR 配置目录下的 `MasterPlayer\Scripts\`，**不要**放进 `Plugins\MasterPlayer\` 插件程序集目录；
  面板「脚本」区有「打开脚本目录」按钮可直接打开）

仓库 `Scripts/` 中的脚本可直接内置：使用 `MasterPlayer.Scripts` 或其子命名空间，继承 `MasterPlayerScript` 并提供公共无参构造函数，按下文标注 `[MechanicScript]`；构建并重载插件后自动出现在脚本列表，无需复制。`Examples/` 示例不会自动加载。

配置目录中成功加载的 `.cs`、`.dll`、可视化脚本与内置脚本名称或 GUID 相同（忽略大小写）时，优先使用配置目录版本。名称是 `[MechanicScript]` 的 `name`（可视化脚本为 `Name`），与文件名无关。外部版本停用时仍覆盖内置版本；移除文件并刷新后恢复内置。编译失败会报告错误，并保留内置版本可用。需要沿用已有设置时保留 GUID；同名不同 GUID 使用各自的设置。

脚本源码里需要的 using（脚本按标准 C# 编译，没有隐式注入的 global usings，请自己写全）：

```csharp
using System.Collections.Generic;
using System.Numerics;
using MasterPlayer.Scripting;                 // MasterPlayerScript / MechanicScript / UserSetting / ScriptColor
using PromeRotation.LogSystem;                // 事件 record（LogSystemCastStartEvent 等）
using MasterPlayer.Spatial.SafeZone;         // GeometryTemplate / TransformBinding
using MasterPlayer.Spatial.Geometry;         // CircleGeometry 等绘制几何
using PromeRotation.Spatial.Drawing;          // DrawStyle / DrawBinding
using PromeRotation.GreenMoveSystem;          // GreenMovePoint
```

## 1. 快速开始

### 1.1 最小脚本

```csharp
using System.Numerics;
using MasterPlayer.Scripting;
using PromeRotation.LogSystem;
using MasterPlayer.Spatial.SafeZone;

[MechanicScript(
    name: "我的第一个机制脚本",
    territorys: [1234],
    guid: "my.first.script.0001",
    version: "0.1.0",
    author: "你的名字",
    note: "读条 5 码钢铁时注册圆形危险区")]
public class MyFirstScript : MasterPlayerScript
{
    protected override void OnStart()
    {
        OnStartCast(e =>
        {
            if (e.ActionId == 12345)   // 换成真实技能 ID
            {
                SafeZone.AddDelayedHit(
                    new CircleTemplate(5f),
                    new FollowEntityPositionAndRotation((uint)e.SourceId, Vector2.Zero, MissingEntityPolicy.RemoveArea),
                    delaySeconds: e.CastTime);
            }
        });
    }
}
```

保存到脚本目录 → 游戏内打开 MasterPlayer 面板（PR 插件管理器 → MasterPlayer 配置 →「打开 MasterPlayer 面板」）→「脚本」区看到脚本 → 勾选启用 → 进入对应副本自动启动。

### 1.2 元数据特性 `[MechanicScript]`（必填）

| 参数 | 类型 | 说明 |
|---|---|---|
| `name` | string | 显示名（脚本列表、设置区标题） |
| `territorys` | uint[] | 适用副本地图 ID 数组，可多个；**空数组 `[]` = 通用脚本，不限区域** |
| `guid` | string | **全局唯一标识，脚本身份主键**：启停状态、每脚本设置、机制开关都以它持久化，一经发布不要更改 |
| `version` | string | 版本号字符串（如 `"1.2.0"`），显示在列表里 |
| `author` | string | 作者名 |
| `note` | string | 备注（可选，显示在脚本详情里） |

区域 ID 可在面板「脚本」区顶部看「当前区域 ID」。

## 2. 生命周期

```csharp
public class MyScript : MasterPlayerScript
{
    protected override void OnStart()               { }  // 启动时一次：事件订阅在这里做
    protected override void OnUpdate(float deltaTime) { } // 每帧调用，deltaTime 单位秒
    protected override void OnStop()                { }  // 停止时一次：脚本自身收尾
}
```

宿主保证：

- **事件回调与 `OnUpdate` 都在游戏主线程执行**，可以直接调 SafeZone / Move / Draw 门面，不需要自己入队换线程。
- 脚本停止时宿主自动清理：全部事件订阅、本脚本注册的全部 SafeZone 区域、本脚本的全部绘制元素。`OnStop` 只做自身状态收尾（以及你自己 `MoveTo` 接管过移动时的 `Move.Stop()`）。
- 区域匹配自动启停：`territorys` 为空时任何区域都可启动；非空时进入匹配区域自动启动、离开自动停止。

需要支持录制回放时，用基类的 `CurrentTime` 代替 `DateTime.UtcNow`。`ReplayWorld` 非空表示回放，提供对象、读条、状态、队伍槽位及玩家位置；此时不能用实时 `Svc.Objects` 补齐缺失对象。暂停不更新脚本，Seek会重建实例和历史状态。新录制v2与旧文件限制见[录制回放格式](录制回放格式.md)。

## 3. 四个门面

脚本基类暴露四个门面属性：`SafeZone` / `Move` / `Draw` / `Settings`（等价于 `Host.SafeZone` 等）。

### 3.1 SafeZone 门面（危险区 / 目标区注册）

转发 `MasterPlayerPlugin.Instance.SafeZone.Registry`，注册即参与插件内 Reborn 解算及绘制。注册方法返回本地 `SafeZoneAreaHandle`，可传给 `Remove(handle)` 提前移除；脚本停止时自动清理自己注册的区域。

插件独立持有配置、区域、场地边界、几何、解算与调度实现。直接设置边界使用 `MasterPlayerPlugin.Instance.SafeZone.Registry`，读取快照使用 `.SafeZone.Manager`，配置与移动结果分别使用 `.SafeZone.Setting` / `.SafeZone.MovementStatus`。旧源码脚本应将 `PromeRotation.Spatial.SafeZone` / `.Geometry` 改为 `MasterPlayer.Spatial.SafeZone` / `.Geometry`，外部 DLL 应重新编译；句柄与几何不能跨插件和本体混用。只修改插件解算时，重新构建并热重载 MasterPlayer 即可。

读条 AOE 使用 `AddDelayedHit` 提供实际判定时间和持续时长。全场预告覆盖时，Reborn 会按危险时间区间规划：先进入后判定区域暂避，等早判定区域结束后转入；移动耗时、安全余量和障碍都参与判断，无可行时间窗口时不会生成冒险转场路线。

需要让用户按 AOE 独立选择绘制位置时，用稳定的分组名包住注册操作：

```csharp
using (SafeZone.BeginDrawingGroup("落雷"))
{
    SafeZone.AddDelayedHit(new CircleTemplate(6f), new StaticTransform(position, 0f), 3f);
}
```

分组首次注册后出现在主面板「AOE 绘制设置」中，可分别选择真实世界、雷达。分组可嵌套，名称按外层／内层组合，退出作用域后恢复外层；不要用实体 ID、当前时间等每次变化的值命名。预测与校正同一个技能时使用相同分组。未指定分组的区域按整个脚本控制。隐藏显示不影响解算；脚本详情中的「机制开关」则控制机制逻辑本身。

与通用躲避去重：插件的通用躲避（DodgeController）会对所有敌方读条自动注册危险区。脚本接管了某些技能后，在 `OnStart` 里声明一次即可让通用躲避跳过它们，避免同一 AOE 注册两遍：

```csharp
protected override void OnStart()
{
    SuppressGenericDodge(48807, 48809); // 本脚本接管的读条技能 ID
}
```

危险区、目标区和硬障碍都由两个视图统一绘制并应用各自配色，硬障碍按危险区显示。不要为同一个 SafeZone 区域再次调用 `Draw.Add` 画重复范围，否则会绕过这些显示设置。

```csharp
// 单次命中（最常用）：delaySeconds 秒后判定，命中窗口默认 0.6 秒
SafeZoneAreaHandle AddDelayedHit(GeometryTemplate template, TransformBinding binding,
    float delaySeconds, float hitDurationSeconds = 0.6f);

// 从现在开始持续 durationSeconds 秒的危险区
SafeZoneAreaHandle AddTimedDanger(GeometryTemplate template, TransformBinding binding, float durationSeconds);

// 永不结束的持续危险区（记得自己 Remove 或等停止清理）
SafeZoneAreaHandle AddPersistentDanger(GeometryTemplate template, TransformBinding binding);

// 目标区（安全点）：引导解算往这里走。落点偏好默认 Nearest——走到离玩家最近的区域内点（贴边）；
// 传 PositionPreference.Center 则回到区域几何中心
SafeZoneAreaHandle AddPersistentSafeArea(GeometryTemplate template, TransformBinding binding,
    int priority = 0, PositionPreference preference = PositionPreference.Nearest);
SafeZoneAreaHandle AddTimedSafeArea(GeometryTemplate template, TransformBinding binding,
    float durationSeconds, int priority = 0, PositionPreference preference = PositionPreference.Nearest);

// 硬障碍（禁止从外部穿入；覆盖玩家时允许立即退出，退出后不得重入）
SafeZoneAreaHandle AddObstacle(GeometryTemplate template, TransformBinding binding);

bool Remove(SafeZoneAreaHandle handle);
```

持续危险区或硬障碍生成在玩家脚下时，Reborn 会立即规划逃离，不等读条结束；重叠区域逐个退出，不能进入其他硬障碍或退出后重入。逃离时自动收紧到达容差，保证走出区域后再停止。场地边界仍然生效，没有可达出口时返回无可达安全格。更新解算器需重新构建并加载 MasterPlayer，仅刷新脚本不会更新内置代码。

几何模板（`MasterPlayer.Spatial.SafeZone`，均为 record）：

| 模板 | 构造 | 说明 |
|---|---|---|
| `CircleTemplate` | `(float Radius)` | 圆，Position=圆心 |
| `DonutTemplate` | `(float InnerRadius, float OuterRadius)` | 月环 |
| `FanTemplate` | `(float Radius, float AngleRadians)` | 扇形，rotation=中心朝向 |
| `RectangleTemplate` | `(float Width, float Length)` | 中心矩形 |
| `RayRectangleTemplate` | `(float MinLocalX, float MaxLocalX, float Length)` | 射线矩形；另有 `RayRectangleTemplate.Symmetric(width, length)` |
| `LocalPolygonTemplate` | `(IEnumerable<Vector2>)` | 局部多边形（LocalX>0 右侧，LocalY<0 前方） |
| `WorldPolygonTemplate` | `(IEnumerable<Vector3>)` | 世界多边形（搭配 StaticTransform） |

变换绑定（TransformBinding 派生）：

| 绑定 | 构造 | 说明 |
|---|---|---|
| `StaticTransform` | `(Vector3 Position, float Rotation)` | 完全静态 |
| `FollowEntityPosition` | `(uint EntityId, Vector2 WorldOffsetXZ, float Rotation, MissingEntityPolicy)` | 跟随实体位置，朝向固定 |
| `FollowEntityPositionAndRotation` | `(uint EntityId, Vector2 LocalOffsetXZ, MissingEntityPolicy)` | 跟随实体当前位置与普通朝向，适用于确认会随实体转动的机制 |
| `FixedPositionFaceEntity` | `(Vector3 Anchor, uint TargetEntityId, float FallbackRotation, MissingEntityPolicy)` | 固定位置朝向目标实体 |
| `BetweenTwoAnchors` | `(AnchorSource A, AnchorSource B, MissingEntityPolicy)` | 两锚点连线；锚点用 `new EntityAnchor(uint)` / `new WorldAnchor(Vector3)` |

`MissingEntityPolicy`：`DisableArea`（实体丢失时本帧跳过）/ `KeepLastResolved`（沿用上次解析）/ `RemoveArea`（直接移除区域）。

角度约定：FFXIV 弧度，0 = +Z，π/2 = +X；世界坐标 X/Z 地面平面，Y 高度。事件里的 `SourceId`/`TargetId` 是 `ulong`，传给门面时 `(uint)` 强转。

固定施法朝向的机制可在读条回调中调用 `CastRotation.TryGet(e, out var rotation)`（`MasterPlayer.Scripting`），再用 `StaticTransform(e.EffectPosition, rotation)` 锁定。该方法仅主线程使用，优先取PR读条包的PacketFacing；实时缺失时才按实体ID匹配正在施放的ActionId，读取FFCS `Character.CastRotation`。回放只取已保存的包朝向，不读取当前游戏对象。朝向不可用时返回false，应记录原因并跳过预测，不能把默认值或普通 `SourceRotation` 当作施法方向。

坐标转换使用 `PromeRotation.Helpers.GeometryHelper.WorldToLocal` / `LocalToWorld`，局部 +X 向右、−Y 向前；朝向和距离使用同一工具的 `ForwardVector3FromRotation`、`PointFromRotationDistanceXZ`、`DistanceXZ` 等。PR 几何的 `GetContours()` 返回世界坐标，不应再次叠加位置或朝向。直线从后端中心向前伸展时用 `RayRectangleTemplate.Symmetric`；`RectangleTemplate` 的位置是矩形中心。

### 3.2 Move 门面（GreenMove 移动）

转发 `PromeRotation.Plugin.Instance.GreenMoveSystem`：

```csharp
bool IsRunning { get; }
GreenMoveStatus GetStatus();
void MoveTo(GreenMovePoint point);                      // 替换当前路线（last-write-wins）
void MoveTo(IReadOnlyList<GreenMovePoint> points);
void Append(GreenMovePoint point);                      // 追加到路线尾
void Stop();                                            // 停止并清空路线
void ClearQueue();                                      // 清后续点，保留当前点
void SkipCurrent();
```

`GreenMovePoint`（`PromeRotation.GreenMoveSystem`）：

```csharp
public readonly record struct GreenMovePoint(
    Vector3 Position,              // 世界坐标目标点
    float Tolerance = 0.2f,        // 到达判定容差
    float SpeedMultiplier = 1.0f,
    bool IgnoreY = true,           // 忽略高度差
    int MaxCastWaitMs = 0,         // 起步时最多等待在读条这么多毫秒；0=不等
    bool WaitForQueuedCast = false // 移动途中让排队读条完成
);
```

**移动纪律（务必遵守）**：

- `MoveTo` 无优先级、last-write-wins：只在路线**变化**时调用，**不要每帧重发**相同路线。
- **只有自己接管过移动才 `Stop()`**，绝不停本体或其他插件发起的移动。
- 插件自动移动或 PR 旧版/Reborn 自动移动开启，或任一安全区持有控制权时，脚本移动门面让位；`Stop` / `ClearQueue` / `SkipCurrent` 不能修改已被安全区接管的路线。通常只需注册本地 SafeZone 区域。PR 自动移动与插件冲突时，可在「总览」点击「关闭 PR 本体安全区自动移动」。回放期间禁止脚本移动和跟随。

### 3.3 Draw 门面（AOE 预览与辅助绘制）

`AddAoe` 提供仅供显示的 AOE 预览，其他方法转发 `PromeRotation.Plugin.Instance.DrawManager`。**传入的 id 会自动加 `MasterPlayer_Script_{guid}_` 前缀**，不同脚本之间不会撞 id；脚本停止时按前缀自动清理。

```csharp
// 不参与解算的 AOE 预览：世界坐标，应用当前 BeginDrawingGroup 及两种视图各自的配色／显示开关
void AddAoe(string id, IGeometryShape geometry, bool safe = false, float durationMs = 0f);

// 静态几何（CircleGeometry / DonutGeometry / FanGeometry / RectangleGeometry 等，命名空间 MasterPlayer.Spatial.Geometry）
DrawHandle Add(string id, IGeometryShape geometry, DrawStyle? style = null,
    float durationMs = 0f, float startDelayMs = 0f);

// 跟随实体：几何用本地坐标（如 new CircleGeometry(Vector3.Zero, r)），binding 用 DrawBinding.Follow(entityId)
DrawHandle AddBound(string id, IGeometryShape geometry, DrawBinding binding, DrawStyle? style = null,
    float durationMs = 0f);

// 连线（多种重载：实体↔实体、实体↔坐标）
DrawHandle AddTether(string id, uint startEntityId, uint endEntityId, DrawStyle? style = null, ...);
DrawHandle AddTether(string id, uint startEntityId, Vector3 end, DrawStyle? style = null, ...);

bool Remove(string id);
```

- `durationMs` 存活毫秒（0 = 直到手动移除/脚本停止），`startDelayMs` 延迟出现。
- `AddAoe` 的 `safe=false` 使用危险区配色，`safe=true` 使用安全区配色；同 id 更新覆盖旧预览，`Remove(id)` 也可移除预览。用于毒气团移动预测等不应进入解算的范围。
- `Add` / `AddBound` / `AddTether` 用于连线、路线标记等辅助世界绘制，保留脚本指定的样式，不自动进入雷达或 AOE 筛选。
- `DrawStyle`：`DrawStyle.Default` / `DrawStyle.Danger`（红）/ `DrawStyle.Safe`（绿），或 `new DrawStyle(fillColor, strokeColor, strokeThickness)`。
- `DrawBinding`：`DrawBinding.Follow(uint entityId, float rotationOffset = 0f)`；`DrawBinding.From(entityId/position).LookAt(target)` / `.To(target)`。

### 3.4 Settings 门面（每脚本设置）

两种方式：

**(a) `[UserSetting]` 属性（推荐）**——public 属性标注后自动出现在面板「脚本设置」里，改动自动持久化到 `MasterPlayer.json`：

```csharp
[UserSetting("圈半径")]
public float Radius { get; set; } = 1.5f;

[UserSetting("提示颜色")]
public ScriptColor Color { get; set; } = new();
```

支持类型：bool / int / float / string / enum / `ScriptColor`（`ScriptColor.V4` 是 `Vector4`，可隐式转 Vector4）。

**注意（与 PromePainter 行为一致）**：面板上修改设置只写入设置存储并持久化，**不会回写脚本实例的属性值**——直接读 `Radius` 属性拿到的始终是构造时的默认值。脚本内读取当前值用 `Settings.GetFloat(nameof(Radius), Radius)` 这种形式（键 = 属性名），面板改动才能生效。

**(b) 键值读写**——`Settings.Get<T>(key, default)` / `Settings.Set(key, value)`，另有 `GetBool` / `GetInt` / `GetFloat` / `GetString` / `Contains`。

## 4. 事件订阅

在 `OnStart` 里订阅，全部经 `PromeEventBus` 按脚本 owner 归属，**停止时自动退订**（返回值 `IDisposable` 一般不用管，想提前退订可自行保存 Dispose）。回调在主线程执行。

```csharp
// 战斗
OnBattleStarted(Action)                    OnBattleEnded(Action)
// 玩家状态
OnPlayerDied(Action)                       OnPlayerRevived(Action)
OnPlayerMoveStateChanged(Action<bool>)
// 环境
OnWeatherChanged(Action<uint>)             OnTerritoryChanged(Action<ushort>)
OnCountdownStarted(Action)
// 日志 / 聊天
OnSystemLog(Action<uint>)                  OnBattleLog(Action<uint>)
OnShowMessage(Action<uint>)                OnChatLog(Action<string, string, string>)
OnLogEvent(Action<LogSystemEvent>)
OnLogEvent<TEvent>(Action<TEvent>) where TEvent : LogSystemEvent   // 泛型版：覆盖无专用 OnXxx 的事件类型
// 战斗事件（LogSystem 事件族，命名空间 PromeRotation.LogSystem）
OnStartCast(Action<LogSystemCastStartEvent>)           OnCancelCast(Action<LogSystemCancelCastEvent>)
OnInterruptCast(Action<LogSystemInterruptCastEvent>)   OnActionEffect(Action<LogSystemActionEffectEvent>)
OnCreateObject(Action<LogSystemObjectCreateEvent>)     OnNpcYell(Action<LogSystemNpcYellEvent>)
OnMapEffect(Action<LogSystemMapEffectEvent>)           OnStatusAdd(Action<LogSystemStatusAddEvent>)
OnStatusRemove(Action<LogSystemStatusRemoveEvent>)     OnTargetIcon(Action<LogSystemTargetIconEvent>)
OnTether(Action<LogSystemTetherEvent>)                 OnTetherCancel(Action<LogSystemTetherCancelEvent>)
OnEObjAnimation(Action<LogSystemEObjAnimationEvent>)   OnEObjSetState(Action<LogSystemEObjSetStateEvent>)
OnPlayActionTimeline(Action<LogSystemPlayActionTimelineEvent>)
OnTargetVfx(Action<LogSystemTargetVfxEvent>)           OnSetObjPos(Action<LogSystemSetObjPosEvent>)
OnMarker(Action<LogSystemMarkerEvent>)                 OnDirectorUpdate(Action<LogSystemDirectorUpdateEvent>)
OnMorelogCompat(Action<LogSystemMorelogCompatEvent>)
// 插件
OnPluginCatalogRefreshed(Action<IReadOnlyList<PromeRotation.DownloadSystem.Plugins.PluginManifest>>)
// 兜底：按事件名订阅
Subscribe(string eventName, Delegate handler)
```

常用事件字段：

- `LogSystemCastStartEvent`：`ActionId`（**ushort**）、`CastTime`（float，秒）、`DurationMilliseconds`、`SourceId` / `TargetId`（ulong）、`EffectPosition`、`SourcePosition`（`Vector3?`）、`SourceRotation`（float）
- `LogSystemTetherEvent`：`SourceId`、`TargetId`、`Category`、`TetherId`、`SourcePosition` / `TargetPosition`（`Vector3?`）
- `LogSystemTargetIconEvent`：`SourceId`、`TargetId`、`MarkerId`

日志：`Log(message)` / `LogError(message)`（写 PR 日志并显示在面板状态/错误栏）。

## 5. 机制开关

脚本可把内部功能拆成可单独开关的「机制」：

```csharp
public override IEnumerable<string> GetMechanisms() => ["画圈提示", "分摊指路"];

private void OnSomething(...)
{
    if (!IsMechanismEnabled("画圈提示"))
        return;
    ...
}
```

返回的每个名称都会在面板脚本详情里显示独立开关，用户选择持久化。**机制开关列表只在脚本运行中可编辑**（需要实例才能枚举）。

## 6. 刷新与调试

- 脚本目录**不做文件监听**：改脚本 `.cs` 文件保存后，到面板「脚本」区点「刷新脚本」手动重载（运行中的实例先 `OnStop` + 清理，再以新编译的程序集重启）。
- **编译错误显示在面板「脚本」区的错误栏**（红字、可滚动看完整编译器输出）；运行时异常会停止该脚本并显示错误，不影响其他脚本。
- 脚本的启用状态、`[UserSetting]` 值、机制开关都持久化在 `MasterPlayer.json`，重启游戏后保留。
- 开发插件本体或内置脚本（仓库 `Scripts/`）走 `dotnet build` → PR 插件管理器热重载 MasterPlayer；「刷新脚本」只会重新发现内置类型，不重新编译插件 DLL。

## 7. 注意事项

1. **主线程**：事件回调与 `OnUpdate` 都在主线程，可直接调三个门面；不要在脚本里再起后台线程碰 SafeZone / DrawManager，也不要订阅 PR 的 `CombatEventManager` 裸事件（那些是 hook/网络线程）。
2. **不要持静态状态**：脚本重启会创建新实例；内置脚本刷新仍使用同一程序集，静态状态不会重置，外部脚本的旧程序集也可能残留。状态一律放实例字段，`OnStop` 收尾。
3. **绘制 id 不用加前缀**：`Draw.Add("foo", ...)` 的 `"foo"` 会自动变成 `MasterPlayer_Script_{guid}_foo`，脚本内用短名即可。
4. **移动让位**：发 `Move.MoveTo` 前确认插件及本体安全区自动移动未接管（见 §3.2）；优先用 SafeZone 注册区域交给插件解算。
5. **guid 是主键**：制作独立脚本时换名称和 GUID，避免覆盖内置脚本；自定义覆盖同一脚本时保留 GUID 以沿用设置。配置目录内多个相同 GUID 仍报重复，只保留先加载的一份。
6. 完整示例见插件仓库 `Examples\ExampleGenericScript.cs`（通用点名圈）与 `Examples\ExampleZoneScript.cs`（区域读条躲避），可直接复制到脚本目录改 guid 后使用。
7. **[UserSetting] 不回写实例属性**：面板改设置只更新 Settings 存储（并持久化到 `MasterPlayer.json`），脚本实例的属性保持构造默认值，不会被回写。读当前设置值一律 `Settings.Get<T>(nameof(属性名), 默认值)`（见 §3.4）。
