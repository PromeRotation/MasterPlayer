# 技能序列

打开侧栏「技能序列」，开启总开关，选择职业并新建或导入预设。每个职业可以保存多套预设，只有标注「执行」且勾选「开战自动执行」的预设生效。总开关默认关闭。

每步可设置技能 ID、是否启用、是否对自己释放、拥有某状态时跳过、需要某状态以及备注。支持步骤上移/下移/删除、预设复制/删除/重命名、循环执行，以及每轮完成后延迟 0～3000ms 执行命令（默认 600ms）。编辑使用下次开战时的配置，当前轮保持启动时的快照。

导入支持原工具箱 `XSZSEQ1:` 分享码、`Version=1/Profile` JSON 和裸预设 JSON；导入到界面当前选择的职业，并生成新预设 ID。导出到剪贴板仍使用 `XSZSEQ1:`。配置保存在自己的 `MasterPlayer.json/SkillSequences`，不读写工具箱配置。

## 执行规则

- 进入战斗后等待 `NormalConditions`，每场启动一次；脱战、死亡、关闭序列、停止本轮、回放或卸载时停止。
- 使用 PR 本体的技能调整、类型、GCD、动画锁和解锁判断；目标优先当前存活敌人，其次最近敌人。明确对自身或零距离技能使用自己。
- 直接逐步调用 PR 的 `ActionUpdaterRouter.UseAction(PAction)`，收到本地玩家对应 `ActionEffect` 后推进，多目标效果按 `GlobalSequence` 去重。无确认最多尝试三次；已观察到读条的技能在读条结束后等待确认，缺失时跳过，避免再次施放。不可用技能等待 1200ms 后跳过；GCD/动画窗口等待不据此超时。
- PR 普通 ACR 原本为 On 时，本轮临时置 Hold；结束或停止后仅在仍为 Hold 时恢复 On。原本 Off/Hold 保持原状态；用户在本轮改成 On/Off 时停止序列，保留该选择。该公开属性没有来源标识，无法识别用户中途改动后又回到 Hold 的同值情况。
- 忍者最终忍术可自动展开天/地/人结印；已有结印状态 496 时直接执行配置步骤，兼容显式结印序列。每印仍通过 PR 释放并等待动作效果。

本模块不清空 PR 全局队列。停止后不会再提交新技能；游戏已接收的单次原生 GCD 请求按游戏自身规则处理。PR 时间轴/其他来源的强制技能仍可能与手动技能一样插入，需要按实际战斗配置协调。

参考 XSZToolbox 的 `Modules/CombatSkillSequenceModule.cs`、`Config/CombatSkillSequenceConfig.cs` 和 `Helpers/Combat/CombatSkillSequenceStore.cs`；完整 UI 参考禁用前提交 `0d2ccd3fb61477e1e8c9e82f614d428fcaa68ba9`。本次编译引用实际安装的 PR `1.5.10.4`，公开接口已与该 DLL 核对。

```text
dotnet build MasterPlayer.csproj -p:CI=true
dotnet run --project tests/MasterPlayer.RegressionTests.csproj -- --filter="Skill Sequence"
dotnet run --project tests/ScriptCompilation/MasterPlayer.ScriptSmoke.csproj -- . bin/Debug/MasterPlayer.dll
```

离线回归覆盖状态条件、确认推进、循环与完成命令、配置快照、分享码和忍术顺序；真实 DLL 冒烟覆盖内置入口发现，以及技能确认去重、读条清理和 ACR 状态恢复。技能效果到达时序和忍术链仍需游戏内验收。
